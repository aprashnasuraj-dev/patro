Compress Image to Exact File Size (KB)

Iteratively compress an image to the closest safe result at or below a requested file-size budget.

Work area

What this tool does

Iteratively compress an image to the closest safe result at or below a requested file-size budget.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Target 200 KB for a 3000×2000 JPEG; the tool searches quality first and optionally downsizes when quality alone cannot meet the target.

Supported formats and units

JPEG, WebP and PNG input; JPEG/WebP output for size targeting.

Assumptions

The target is treated as an upper bound, not a promise of byte-perfect equality.

Limitations

Encoder output is discrete; exact byte size may be impossible. Very small targets may require reduced dimensions.
