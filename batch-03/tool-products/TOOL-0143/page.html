Split PDF by Bookmarks (Chapters)

Read top-level PDF outline destinations and split the document into chapter PDFs at bookmark boundaries.

Work area

What this tool does

Read top-level PDF outline destinations and split the document into chapter PDFs at bookmark boundaries.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

A manual with bookmarks Introduction, Setup and Reference becomes three chapter PDFs in a ZIP.

Supported formats and units

PDF input; multiple PDF outputs in ZIP.

Assumptions

Only bookmarks that resolve to valid pages are used; unresolved outline items are reported.

Limitations

PDF outlines do not always map cleanly to chapter boundaries; nested or out-of-order destinations may need manual review.
