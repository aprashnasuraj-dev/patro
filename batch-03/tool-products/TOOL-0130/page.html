Work area

What this tool does

Rasterize a sanitized SVG to exact PNG or JPEG dimensions entirely in the browser.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Export a 24×24 icon SVG at 512×512 PNG and a 1200×630 JPEG social image with a chosen background.

Supported formats and units

SVG input; PNG/JPEG output.

Assumptions

External scripts/resources are removed and remote URL references are not fetched.

Limitations

Unsupported external fonts or filters may render differently from the original authoring environment.
