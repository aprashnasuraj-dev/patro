Bulk EXIF Viewer and Stripper

Inspect common EXIF metadata across local images, then create metadata-stripped copies without uploading originals.

Work area

What this tool does

Inspect common EXIF metadata across local images, then create metadata-stripped copies without uploading originals.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Select a folder of JPEG photos, review camera/date/GPS fields, then export cleaned copies.

Supported formats and units

JPEG, PNG and WebP; HEIC metadata viewing depends on the local decoder.

Assumptions

Metadata removal is performed on newly encoded output; originals are never modified.

Limitations

Re-encoding can change compression and colour-profile metadata; metadata stripping is not a forensic anonymity guarantee.
