Reduce PDF Size by Image Downsampling

Create a smaller rasterized PDF by downsampling pages and recompressing them at chosen DPI and JPEG quality. Files stay in this browser during normal use.

Workspace

Quick start

Start at 120 DPI and JPEG quality 0.72 for a reviewable tradeoff.

Supported inputs: PDF, DPI, JPEG quality, grayscale. Oversized, malformed, encrypted or unsupported inputs return an explicit error instead of a guessed result.

Assumptions and limitations

This staging source favors local processing and bounded memory use. PDF text/table interpretation depends on how the source PDF encodes content; image-only pages require OCR, which these tools do not silently invoke. Outputs should be visually reviewed before high-stakes use.

Worked example

Start at 120 DPI and JPEG quality 0.72 for a reviewable tradeoff. The result panel explains the chosen page dimensions, render resolution or conversion warnings before export.
