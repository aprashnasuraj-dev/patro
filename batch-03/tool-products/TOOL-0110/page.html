What this tool does
Generate a fluid font-size clamp() from minimum/maximum sizes and viewport widths, with the linear interpolation shown explicitly and bounded by CSS clamp semantics.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
16px at 320px and 24px at 1280px becomes a clamp with a calculated vw slope and px/rem intercept.
Supported formats and units
Input sizes and viewport widths in CSS pixels; output in px or rem plus vw.
Assumptions
The desired scale is linear between the two viewport widths and non-decreasing.
Limitations
Browser zoom, user minimum-font settings, container width, and design breakpoints may make viewport-linear typography inappropriate for some interfaces.
