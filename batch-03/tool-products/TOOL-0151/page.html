Images to PDF with Page Size and Margin Control

Combine local images into a PDF with explicit page size, orientation, margins and fit behavior. Files stay in this browser during normal use.

Supported inputs: images, page size, orientation, margin, fit. Oversized, malformed, encrypted or unsupported inputs return an explicit error instead of a guessed result.

Assumptions and limitations

This staging source favors local processing and bounded memory use. PDF text/table interpretation depends on how the source PDF encodes content; image-only pages require OCR, which these tools do not silently invoke. Outputs should be visually reviewed before high-stakes use.
