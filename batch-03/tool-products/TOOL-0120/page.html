What this tool does
Build Google Fonts CSS2 stylesheet URLs for one or more families, axis tuples/ranges, display mode and optional text optimization while enforcing the documented ordering rules.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
Roboto with wght 400 and 700 plus Roboto Flex wght 100..1000 becomes two family= parameters on fonts.googleapis.com/css2.
Supported formats and units
Google Fonts family names, four-character axis tags, numeric axis values/ranges, optional UTF-8 text parameter, CSS  snippet.
Assumptions
The family and requested axis/value combinations actually exist in Google Fonts.
Limitations
This builder does not call Google to validate availability. Google may reject unsupported families, axes, values, overlapping tuples or malformed combinations.

FAQ
Does this send my input to a server?
No. The prepared implementation is browser-first and normal tool use is designed for local execution.
Is the output guaranteed to match every browser or font?
No. The limitations above identify the important environment, parser, shaping, and availability differences.
