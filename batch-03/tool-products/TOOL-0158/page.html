PDF Page Size Inspector

Inspect each PDF page size, rotation and user-unit-scaled physical dimensions. Files stay in this browser during normal use.

Quick start

Inspect A4, Letter and custom page dimensions in mm/in/pt.

Supported inputs: PDF, units. Oversized, malformed, encrypted or unsupported inputs return an explicit error instead of a guessed result.

Assumptions and limitations

This staging source favors local processing and bounded memory use. PDF text/table interpretation depends on how the source PDF encodes content; image-only pages require OCR, which these tools do not silently invoke. Outputs should be visually reviewed before high-stakes use.
