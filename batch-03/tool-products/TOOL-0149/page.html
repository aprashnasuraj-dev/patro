Crop PDF Margins Visually

Preview PDF pages and set crop boxes using explicit point/mm/inch margins without rasterizing page content.

Work area

What this tool does

Preview PDF pages and set crop boxes using explicit point/mm/inch margins without rasterizing page content.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Remove 12 mm white margins from all sides of a scanned report by adjusting each page crop box.

Supported formats and units

PDF input and PDF output.

Assumptions

Cropping changes the visible crop box; underlying content outside the crop can remain in the file.

Limitations

Cropping is not redaction. Hidden content outside the crop box may still be recoverable.
