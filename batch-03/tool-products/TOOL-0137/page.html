GIF Speed Changer and Reverser

Adjust animated GIF frame delays, optionally reverse frame order and re-encode the result locally.

Work area

What this tool does

Adjust animated GIF frame delays, optionally reverse frame order and re-encode the result locally.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Set speed to 1.5× and reverse a reaction GIF while preserving its loop setting.

Supported formats and units

GIF input and GIF output.

Assumptions

Frame delays are clamped to a safe minimum because some viewers ignore extremely small delays.

Limitations

Re-encoding may change palette quantization and file size; timing precision varies by GIF viewer.
