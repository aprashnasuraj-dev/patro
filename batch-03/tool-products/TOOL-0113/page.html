What this tool does

Extract a browser-local glyph map from an icon or symbol font, including glyph index, Unicode mappings, glyph name and Private Use Area flags, then export JSON or CSV.

How to use it

Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.

Worked example

Upload an icon font and identify U+E001 → glyph “home”, with PUA mappings highlighted for documentation.

Supported formats and units

TTF, OTF or WOFF2 input; JSON/CSV output.

Assumptions

Unicode mapping data is present in the font cmap and glyph names, when shown, are meaningful to the font author.

Limitations

Unencoded glyphs have no Unicode character. Icon-font naming conventions are not standardized, and some fonts intentionally omit glyph names.

Authoritative references

  • opentype.js 2.0.0
  • OpenType 1.9.1

FAQ

Does this send my input to a server?

No. The prepared implementation is browser-first and normal tool use is designed for local execution.

Is the output guaranteed to match every browser or font?

No. The limitations above identify the important environment, parser, shaping, and availability differences.
