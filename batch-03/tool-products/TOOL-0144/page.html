Merge PDFs with Bookmarks per File

Merge multiple PDFs locally and add one top-level bookmark at the first page of each source file.

Work area

What this tool does

Merge multiple PDFs locally and add one top-level bookmark at the first page of each source file.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Merge three reports and create bookmarks “January”, “February” and “March” at their starting pages.

Supported formats and units

Multiple PDF inputs; one PDF output.

Assumptions

Bookmark labels default to sanitized filenames and can be edited before export.

Limitations

Encrypted files, signatures and complex interactive features may not survive merging; outline writing uses a tested integration helper that still requires deferred QA.
