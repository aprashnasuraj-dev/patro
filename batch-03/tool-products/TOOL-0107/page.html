What this tool does
Build a standards-shaped @font-face block, validate unicode-range tokens, and optionally derive compact ranges from pasted sample text without sending font or text data anywhere.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
For a Latin subset, family “Example Sans”, source “example.woff2”, and U+0000-00FF produces a noindex-ready @font-face rule with explicit format and display descriptors.
Supported formats and units
CSS @font-face output. Source formats: WOFF2, WOFF, TrueType, OpenType. unicode-range accepts U+hex, U+start-end and wildcard forms such as U+4??.
Assumptions
The source URL is already deployable and the declared format matches the actual font resource.
Limitations
This tool validates syntax and Unicode bounds, not whether the source font actually contains every declared code point or whether a browser will download a particular subset.

FAQ
Does this send my input to a server?
No. The prepared implementation is browser-first and normal tool use is designed for local execution.
Is the output guaranteed to match every browser or font?
No. The limitations above identify the important environment, parser, shaping, and availability differences.
