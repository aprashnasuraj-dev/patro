What this tool does

Inspect a PDF locally with PDF.js and list fonts encountered in page text, including family/name signals and whether embedded binary data is positively exposed by the parser.

How to use it

Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.

Worked example

Open a PDF and get a deduplicated table of encountered fonts, page counts, subset-like names and embedded status of yes or unknown.

Supported formats and units

PDF up to 50 MB and up to 500 pages; table/CSV output.

Assumptions

Fonts encountered by PDF.js while extracting page text represent the fonts materially used on those pages.

Limitations

Unused resource fonts, some XFA/content paths, scanned-image PDFs and parser-internal font details may be absent. “Unknown” embedded status must not be treated as “not embedded”.

FAQ

Does this send my input to a server?

No. The prepared implementation is browser-first and normal tool use is designed for local execution.

Is the output guaranteed to match every browser or font?

No. The limitations above identify the important environment, parser, shaping, and availability differences.
