Image Difference Comparator

Compare two same-size images pixel by pixel and export a visual diff plus quantitative mismatch metrics.

Work area

What this tool does

Compare two same-size images pixel by pixel and export a visual diff plus quantitative mismatch metrics.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Compare baseline.png and current.png at threshold 16, then inspect mismatch percentage and amplified diff.

Supported formats and units

PNG/JPEG/WebP/AVIF images supported by the browser.

Assumptions

Images must be the same dimensions unless the user explicitly chooses normalization.

Limitations

Pixel differences are sensitive to colour management, antialiasing and lossy compression and are not equivalent to perceptual similarity.
