App Icon Set Generator (iOS and Android)

Create browser-local iOS and Android raster icon sets plus integration manifests from a single high-resolution master.

Work area

What this tool does

Create browser-local iOS and Android raster icon sets plus integration manifests from a single high-resolution master.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Use a 1024 px master to produce iOS marketing artwork and Android density assets, then download one ZIP.

Supported formats and units

PNG/JPEG/WebP source; PNG outputs.

Assumptions

The source should be square and at least 1024×1024 for high-density targets.

Limitations

Platform tooling evolves; generated legacy density sets complement, not replace, Xcode/Android Studio asset validation.
