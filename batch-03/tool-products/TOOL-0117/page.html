TextMetrics details
What this tool does
Measure text width with the browser canvas text engine, including font style, weight and optional letter spacing, and visualize the measured inline box.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
Measure “Pricing — 2026” at 32 px in a chosen font and see width, actual bounding-box metrics and the effect of 0.5 px tracking.
Supported formats and units
Unicode text; CSS font-family/weight/style; size and letter spacing in CSS pixels.
Assumptions
Canvas TextMetrics in the current browser is representative of the target rendering environment.
Limitations
Results are browser-, OS-, font-availability- and rasterizer-dependent. CSS layout can add effects not represented by a simple canvas measurement.
Authoritative references
  • CSS Font Loading Module Level 3 Working Draft
FAQ
Does this send my input to a server?
No. The prepared implementation is browser-first and normal tool use is designed for local execution.
Is the output guaranteed to match every browser or font?
No. The limitations above identify the important environment, parser, shaping, and availability differences.
