What this tool does

Check which of several local font files cover each requested Unicode character and report complete, partial, or missing coverage without transmitting the fonts.

How to use it

Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.

Worked example

Upload three fonts and paste “A नेपाल 😀”; the matrix shows exactly which file maps each distinct Unicode code point.

Supported formats and units

Up to 12 TTF, OTF or WOFF2 files, each up to 30 MB; Unicode text input.

Assumptions

A cmap mapping is treated as font support for the code point.

Limitations

A cmap entry does not guarantee visually correct shaping, mark positioning, emoji presentation, or language-quality support.

Authoritative references

  • OpenType 1.9.1

FAQ

Does this send my input to a server?

No. The prepared implementation is browser-first and normal tool use is designed for local execution.

Is the output guaranteed to match every browser or font?

No. The limitations above identify the important environment, parser, shaping, and availability differences.
