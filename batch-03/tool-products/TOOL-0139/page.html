Image DPI Changer (72 to 300 DPI)

Change PNG or JPEG resolution metadata without resampling pixels, so physical print dimensions change while pixel dimensions remain constant.

Work area

What this tool does

Change PNG or JPEG resolution metadata without resampling pixels, so physical print dimensions change while pixel dimensions remain constant.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Set a 3000×2400 JPEG from 72 DPI to 300 DPI; pixel dimensions stay 3000×2400 while nominal print size becomes 10×8 inches.

Supported formats and units

PNG and JPEG.

Assumptions

DPI is metadata only in this tool; it does not create additional image detail.

Limitations

Some software ignores or rewrites density metadata, and browser canvas export normally defaults to 96 DPI.
