What this tool does
Compose a practical CSS font-family stack from a category template, optional preferred fonts, and a standards-defined generic fallback.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
Choose “system UI”, put Inter first, and get a stack that tries Inter, platform UI fonts, then system-ui and sans-serif.
Supported formats and units
CSS font-family declaration and raw comma-separated stack.
Assumptions
Named fonts may or may not exist on the visitor’s operating system; the final generic family is the only portable category guarantee.
Limitations
“Web-safe” is probabilistic for named local fonts. Rendering metrics and glyph coverage vary by platform and version.
Authoritative references
  • CSS Fonts Module Level 4 Working Draft
FAQ
Does this send my input to a server?
No. The prepared implementation is browser-first and normal tool use is designed for local execution.
Is the output guaranteed to match every browser or font?
No. The limitations above identify the important environment, parser, shaping, and availability differences.
