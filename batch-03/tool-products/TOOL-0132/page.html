BlurHash and ThumbHash Generator

Generate compact BlurHash and ThumbHash placeholders locally and preview their decoded appearance.

Work area

What this tool does

Generate compact BlurHash and ThumbHash placeholders locally and preview their decoded appearance.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Open a product image, generate a 4×3 BlurHash plus ThumbHash, then copy strings/data for application use.

Supported formats and units

Browser-decodable raster image input; text/base64 hash output.

Assumptions

Official/reference-compatible local packages are lazy-loaded on demand.

Limitations

Hashes are placeholders, not compression formats and not suitable for recovering original image detail.

Authoritative implementation references are recorded in research/sources.json.
