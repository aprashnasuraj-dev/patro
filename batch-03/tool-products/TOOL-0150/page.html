Resize PDF Pages to A4 or Letter

Place each source PDF page onto new A4 or Letter pages with contain, cover or stretch fit and configurable margins.

Work area

What this tool does

Place each source PDF page onto new A4 or Letter pages with contain, cover or stretch fit and configurable margins.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Normalize mixed-size scans onto A4 portrait pages with 10 mm margins using contain mode.

Supported formats and units

PDF input and PDF output.

Assumptions

Source pages are embedded into new target pages; vector content remains vector where supported by the library.

Limitations

Page resizing can alter print scale and invalidate signatures; annotations/forms may not transfer with all semantics.
