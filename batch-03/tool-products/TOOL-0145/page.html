Bates Numbering for PDFs

Apply sequential Bates labels to every PDF page with configurable prefix, zero padding, position and typography.

Work area

What this tool does

Apply sequential Bates labels to every PDF page with configurable prefix, zero padding, position and typography.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Start at 1001 with prefix CASE- and six digits to produce CASE-001001, CASE-001002, and so on.

Supported formats and units

PDF input and PDF output.

Assumptions

Numbers are drawn into page content on a newly saved PDF.

Limitations

Bates stamping changes the file and invalidates existing digital signatures.
