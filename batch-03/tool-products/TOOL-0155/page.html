True PDF Redaction (Rasterize Redacted Pages)

Apply irreversible local redactions by rasterizing redacted pages into a newly created PDF. Files stay in this browser during normal use.

Workspace

Quick start

Mark sensitive text, then rasterize only those pages at 200 DPI.

Supported inputs: PDF, page, redaction rectangles, render DPI, fill. Oversized, malformed, encrypted or unsupported inputs return an explicit error instead of a guessed result.

Assumptions and limitations

This staging source favors local processing and bounded memory use. PDF text/table interpretation depends on how the source PDF encodes content; image-only pages require OCR, which these tools do not silently invoke. Outputs should be visually reviewed before high-stakes use.

Worked example

Mark sensitive text, then rasterize only those pages at 200 DPI. The result panel explains the chosen page dimensions, render resolution or conversion warnings before export.
