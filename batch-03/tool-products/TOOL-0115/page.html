What this tool does

Measure kerning adjustments for adjacent glyph pairs in a sample string using a local font and show design-unit and pixel adjustments at a chosen size.

How to use it

Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.

Worked example

Upload a font and test “AVATAR To”; pairs such as A–V and T–o are listed with negative or positive spacing adjustments.

Supported formats and units

TTF, OTF or WOFF2 input; sample Unicode text; design units and CSS-pixel equivalents.

Assumptions

The font parser resolves the font’s kerning implementation for the selected glyph pair.

Limitations

This is sample-pair inspection, not exhaustive expansion of all class/context kerning. Browser shaping can differ because script, language and feature resolution may affect positioning.

FAQ

Does this send my input to a server?

No. The prepared implementation is browser-first and normal tool use is designed for local execution.

Is the output guaranteed to match every browser or font?

No. The limitations above identify the important environment, parser, shaping, and availability differences.
