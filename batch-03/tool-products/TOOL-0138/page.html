APNG and Animated WebP Converter

Decode APNG or animated WebP locally and convert bounded animations to GIF with explicit colour/timing limitations.

Work area

What this tool does

Decode APNG or animated WebP locally and convert bounded animations to GIF with explicit colour/timing limitations.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Open an animated WebP with 24 frames and export a looping GIF at the original timing.

Supported formats and units

APNG or animated WebP input; GIF output.

Assumptions

The browser ImageDecoder API is preferred where available, with a local APNG decoder fallback.

Limitations

GIF is limited to indexed colour and can be much larger or lower quality than APNG/WebP.
