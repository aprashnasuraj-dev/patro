Passport and ID Photo Cropper by Country

Work area

What this tool does

Crop a local portrait against officially sourced passport-photo dimensions for supported jurisdictions, or use a clearly labeled custom preset.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Choose UK printed passport: 35×45 mm with the official head-height guide, position the portrait, then export a print-ready crop.

Supported formats and units

JPEG/PNG input; JPEG/PNG output. Presets: US, UK, Canada and Australia plus custom.

Assumptions

The tool applies geometry guides only; it does not certify pose, lighting, identity or application acceptance.

Limitations

Government photo rules can change and some jurisdictions forbid or restrict digital alteration. Always re-check the linked official authority before submission.
