PDF Watermark (Text, Image, Tiled)

Apply text or image watermarks to PDF pages locally, including centred and tiled layouts.

Work area

What this tool does

Apply text or image watermarks to PDF pages locally, including centred and tiled layouts.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Add a 30% opacity “DRAFT” watermark rotated 45° across every page.

Supported formats and units

PDF input; optional PNG/JPEG watermark image; PDF output.

Assumptions

Watermarks are added as new page content, not as annotations.

Limitations

Watermarks are deterrents, not access controls; recipients with PDF-editing tools may be able to remove them.
