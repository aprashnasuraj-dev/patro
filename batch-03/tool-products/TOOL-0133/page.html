Work area

What this tool does

Preview an image as a 3×3 tile, quantify opposite-edge mismatch and optionally create an offset working copy for seam repair.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Load a fabric texture, inspect a high vertical edge score, offset by 50%, edit externally if needed, then re-check.

Supported formats and units

PNG/JPEG/WebP input; PNG working-copy output.

Assumptions

Edge mismatch is computed from sampled RGB differences along opposite borders.

Limitations

A low numeric edge score does not prove a pattern is visually seamless, especially for structured motifs.
