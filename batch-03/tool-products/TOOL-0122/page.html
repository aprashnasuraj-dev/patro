HEIC to JPG Batch Converter

Convert HEIC/HEIF photos to JPEG locally in the browser with bounded batch processing.

Work area

What this tool does

Convert HEIC/HEIF photos to JPEG locally in the browser with bounded batch processing.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Drop 12 iPhone HEIC photos, choose JPEG quality 90, then download a ZIP of converted images.

Supported formats and units

HEIC/HEIF input; JPEG output.

Assumptions

A bundled libheif/WASM decoder is lazy-loaded only after this route opens.

Limitations

HDR/wide-gamut source data may be tone-mapped to the browser canvas colour space; metadata is not preserved by default.

References

Authoritative implementation references are recorded in research/sources.json.
