What this tool does
Convert text into SVG path data locally using an uploaded font, with configurable size, fill and padding and a downloadable standalone SVG.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
Upload a font, enter “Mangal”, choose 96 px, and export a viewBox-fitted SVG containing path outlines rather than text elements.
Supported formats and units
TTF, OTF or WOFF2 font input; UTF-8 text; SVG path/SVG document output.
Assumptions
The font parser can map the requested characters to glyph outlines.
Limitations
Path conversion is not a full browser shaping engine. Complex-script shaping, color glyphs, SVG-in-OpenType and variation-instance behavior may differ or be unsupported.
Authoritative references
  • opentype.js 2.0.0
  • OpenType 1.9.1
FAQ
Does this send my input to a server?
No. The prepared implementation is browser-first and normal tool use is designed for local execution.
Is the output guaranteed to match every browser or font?
No. The limitations above identify the important environment, parser, shaping, and availability differences.
