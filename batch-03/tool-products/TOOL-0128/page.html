CSS Sprite Sheet Generator

Pack multiple local images into a sprite sheet and generate deterministic CSS background-position rules.

Work area

What this tool does

Pack multiple local images into a sprite sheet and generate deterministic CSS background-position rules.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Drop 20 32×32 icons, set 4 px padding and a .icon- prefix, then export sprite.png and sprite.css.

Supported formats and units

PNG/JPEG/WebP/SVG images decoded by the browser; PNG sprite output.

Assumptions

A shelf-packing layout is used for predictable ordering and bounded complexity.

Limitations

Sprite sheets can hurt modern responsive/image-loading workflows; use them where a single request and CSS positioning are actually beneficial.
