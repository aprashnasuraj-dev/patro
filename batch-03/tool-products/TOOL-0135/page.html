Work area

What this tool does

Draw local redaction regions and flatten blur, pixelation or solid-fill effects into a new image.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Drag a box over a licence plate, choose solid fill for strongest concealment, then export the flattened JPEG.

Supported formats and units

PNG/JPEG/WebP input; PNG/JPEG output.

Assumptions

Only the exported raster copy is changed; the original file stays untouched.

Limitations

Blur and pixelation can leak information and are not secure redaction methods. Use solid fill for sensitive data.
