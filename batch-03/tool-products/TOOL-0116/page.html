What this tool does
Detect four-character OpenType feature tags in GSUB and GPOS tables and generate a conservative CSS font-feature-settings helper for selected features.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
A font containing liga, kern and smcp is reported with feature meanings and can generate font-feature-settings: "liga" 1, "smcp" 1;
Supported formats and units
TTF, OTF or WOFF2 input; CSS feature-settings output.
Assumptions
Presence in a FeatureList means the font defines the feature tag, not that it affects every script, language, glyph or variation instance.
Limitations
The tool does not execute shaping or prove that enabling a tag is typographically appropriate. Prefer higher-level font-variant properties where suitable.

FAQ
Does this send my input to a server?
No. The prepared implementation is browser-first and normal tool use is designed for local execution.
Is the output guaranteed to match every browser or font?
No. The limitations above identify the important environment, parser, shaping, and availability differences.
