What this tool does
Compare a primary and fallback font locally and generate size-adjust plus ascent/descent/line-gap overrides designed to reduce layout shift during font fallback.
How to use it
Provide the task-specific input above, run the primary action, review warnings and intermediate details, and copy or export only after the result matches your intent.
Worked example
Upload a primary and fallback font, choose x-height matching, and the tool calculates a fallback @font-face rule whose adjusted x-height and typographic line metrics approximate the primary font.
Supported formats and units
TTF, OTF, or WOFF2 input up to 30 MB each. CSS percentage descriptors as output.
Assumptions
Both files expose comparable typographic metrics. x-height and cap-height matching use OS/2 metrics when available.
Limitations
Metric matching reduces geometric differences but cannot make glyph shapes, hinting, kerning, or script shaping identical. Variable-font instance metrics can differ from default metrics.

FAQ
Does this send my input to a server?
No. The prepared implementation is browser-first and normal tool use is designed for local execution.
Is the output guaranteed to match every browser or font?
No. The limitations above identify the important environment, parser, shaping, and availability differences.
