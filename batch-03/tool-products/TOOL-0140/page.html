Bulk Image Resizer with Format Conversion

Resize a bounded batch of images with contain/cover/stretch modes and optionally convert formats before ZIP download.

Work area

What this tool does

Resize a bounded batch of images with contain/cover/stretch modes and optionally convert formats before ZIP download.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Resize 40 photos to fit within 1600×1600 WebP at quality 82 and download one ZIP.

Supported formats and units

Browser-decodable raster images; PNG/JPEG/WebP output.

Assumptions

Processing is sequential with cancellation to limit peak memory.

Limitations

Animated inputs are treated as still images unless the animation-specific tools are used.

Authoritative implementation references are recorded in research/sources.json.
