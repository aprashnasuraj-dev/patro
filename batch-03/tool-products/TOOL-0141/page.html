PDF Metadata Viewer and Scrubber

Inspect standard PDF document-info metadata and create a copy with common metadata fields cleared locally.

Work area

What this tool does

Inspect standard PDF document-info metadata and create a copy with common metadata fields cleared locally.

How to use it

  1. Choose local input files and review the task-specific controls.
  2. Run the tool. Processing stays in this browser session.
  3. Review warnings and previews before copying or downloading output.

Worked example

Review title, author, subject, keywords, producer and dates, then export a scrubbed copy.

Supported formats and units

PDF input and PDF output.

Assumptions

The tool clears metadata accessible through the local PDF library and reports what it changed.

Limitations

This is not forensic sanitization: incremental revisions, XMP packets, attachments or hidden content may remain depending on the file.
