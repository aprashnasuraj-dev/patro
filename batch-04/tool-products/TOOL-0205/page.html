Chi-Square Test of Independence Calculator

Analyze an RxC contingency table with Pearson chi-square, degrees of freedom, expected counts, standardized residuals, and Cramér's V. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Analyze an RxC contingency table with Pearson chi-square, degrees of freedom, expected counts, standardized residuals, and Cramér's V.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Counts are mutually exclusive classifications of independent observations.

Limitations

Pearson chi-square relies on adequate expected counts and independent observations. Sparse tables may require exact or Monte Carlo methods.

FAQ

What if expected counts are small?

The tool warns when expected cells are below 5; sparse tables may need exact or simulation-based inference.
