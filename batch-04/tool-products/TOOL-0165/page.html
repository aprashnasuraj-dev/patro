What this tool does

Rotate video by 90-degree steps and flip horizontally or vertically with local processing.

Engineering basis: FFmpeg transpose and flip filters.

How to use it

  1. Choose or paste the input.
  2. Review the bounded controls and defaults.
  3. Run the local operation, inspect the result, then download/export.

Example

Rotate a sideways phone recording 90° clockwise and clear stale orientation metadata.

Formats & assumptions

Media decoding/encoding support is supplied by a same-origin lazy FFmpeg/WASM integration.

Limitations

Rotation/flip changes pixels and therefore requires re-encoding; orientation metadata is cleared.

FAQ

Does my file leave the device? No in normal use; processing is designed to run locally. Why are there limits? Browser memory and CPU are finite, so oversized work is rejected rather than risking a tab crash.
