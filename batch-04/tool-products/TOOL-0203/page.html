Wilson Score Confidence Interval Calculator

Calculate a Wilson score interval for a binomial proportion, including boundary cases such as zero or all successes. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Calculate a Wilson score interval for a binomial proportion, including boundary cases such as zero or all successes.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Independent Bernoulli trials with one common underlying success probability.

Limitations

The interval describes repeated-sampling coverage under a binomial model. It is not a Bayesian credible interval and does not correct for clustered or dependent trials.

FAQ

Why Wilson instead of Wald?

Wilson intervals behave much better near 0 and 1 and for modest sample sizes.
