Exponential Smoothing and Moving Average Calculator

Smooth and forecast a univariate series with simple exponential smoothing and compare it with a trailing moving average. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Smooth and forecast a univariate series with simple exponential smoothing and compare it with a trailing moving average.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Observations are ordered in time and equally spaced for moving-average interpretation.

Limitations

Simple exponential smoothing is appropriate for level-only series without explicit trend or seasonality. This tool does not fit Holt/Holt-Winters models.

FAQ

Does SES model trend?

No. This implementation is level-only simple exponential smoothing.
