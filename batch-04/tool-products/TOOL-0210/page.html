Outlier Detector (IQR, Z-Score, MAD)

Flag potential outliers side by side using Tukey IQR fences, conventional Z-scores, and robust modified Z-scores based on MAD. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Flag potential outliers side by side using Tukey IQR fences, conventional Z-scores, and robust modified Z-scores based on MAD.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Thresholds are user-selectable diagnostics applied to a single numeric variable.

Limitations

Outlier flags are diagnostics, not automatic deletion rules. Z-score methods are sensitive to distribution shape; MAD can be zero.

FAQ

Should flagged points be deleted?

No. Flags identify observations worth investigating; deletion requires a substantive data-quality or modeling reason.
