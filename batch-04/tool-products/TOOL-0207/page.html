Mann-Whitney U Test Calculator

Run a Mann–Whitney U test with exact enumeration for small no-tie samples and a tie-corrected normal approximation otherwise. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Run a Mann–Whitney U test with exact enumeration for small no-tie samples and a tie-corrected normal approximation otherwise.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Independent ordinal/continuous observations; for a location interpretation, group distributions should have compatible shapes.

Limitations

The exact branch is only used for small samples without ties. With ties, especially in small samples, a permutation method is preferable.

FAQ

When is the exact p-value used?

Only for small, no-tie samples. Ties invalidate the simple exact rank distribution used here.
