Survey Sample Size Calculator (Finite Population)

Estimate survey responses for a target margin of error, then apply finite-population correction, design effect, and response-rate inflation. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Estimate survey responses for a target margin of error, then apply finite-population correction, design effect, and response-rate inflation.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Simple random sampling before the user-supplied design-effect multiplier.

Limitations

The simple random-sampling formula does not replace a full complex-survey design. Design effect and response rate are user assumptions.

FAQ

Why is p=0.5 the default?

For a proportion, p=0.5 maximizes p(1-p) and therefore gives the most conservative simple-random-sample size when prevalence is unknown.
