A/B Test Sample Size Calculator

Plan control and treatment sample sizes for two independent proportions using alpha, power, target effect, and allocation ratio. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Plan control and treatment sample sizes for two independent proportions using alpha, power, target effect, and allocation ratio.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Independent binary outcomes and a fixed design analyzed with a z-test after the planned sample is collected.

Limitations

This is a normal-approximation planning formula; sequential testing, multiple metrics, clustering, CUPED/covariate adjustment, and over-dispersion require a different design.

FAQ

Is the result per variant?

The tool reports control, treatment, and total sample sizes explicitly.

Can I use this for sequential tests?

No. Fixed-horizon normal-approximation planning and sequential monitoring require different error-control methods.
