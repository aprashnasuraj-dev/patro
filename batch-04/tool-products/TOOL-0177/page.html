What this tool does

Estimate tempo from audio using onset-energy autocorrelation and show confidence plus half/double-tempo alternatives.

Engineering basis: Web Audio decoding plus local signal analysis.

How to use it

  1. Choose or paste the input.
  2. Review the bounded controls and defaults.
  3. Run the local operation, inspect the result, then download/export.

Example

Estimate whether a dance track is approximately 128 BPM and inspect 64/256 alternatives.

Formats & assumptions

The tool uses browser-local parsing/analysis and does not transmit input to a service.

Limitations

BPM is a heuristic estimate, not a beat-grid transcription. Half/double-tempo ambiguity is explicitly surfaced.

FAQ

Does my file leave the device? No in normal use; processing is designed to run locally. Why are there limits? Browser memory and CPU are finite, so oversized work is rejected rather than risking a tab crash.
