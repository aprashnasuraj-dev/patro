Correlation Matrix from CSV (Pearson and Spearman)

Build a Pearson or Spearman correlation matrix from numeric CSV columns using pairwise-complete observations. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Build a Pearson or Spearman correlation matrix from numeric CSV columns using pairwise-complete observations.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Headers identify numeric variables; missing values are blank; non-missing pairs are used per matrix cell.

Limitations

Pairwise deletion can produce different N for each cell and a matrix that is not positive semidefinite. Correlation does not imply causation.

FAQ

Why do N values vary by cell?

Missing values are handled pairwise, so each correlation can use a different subset of complete pairs.
