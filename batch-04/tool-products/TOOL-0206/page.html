Welch t-Test Calculator from Pasted Data

Run Welch's unequal-variance two-sample t-test from pasted observations with Welch-Satterthwaite degrees of freedom and a mean-difference confidence interval. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Run Welch's unequal-variance two-sample t-test from pasted observations with Welch-Satterthwaite degrees of freedom and a mean-difference confidence interval.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Two independent samples; observations within each sample are independent.

Limitations

Welch's test targets a difference in means under independent sampling. Severe non-normality or dependence can invalidate small-sample inference.

FAQ

Why Welch instead of pooled t-test?

Welch does not require equal population variances and adjusts the degrees of freedom accordingly.

Method references
