What this tool does

Reorder, rename, or drop CSV columns using an explicit column plan, preserving row data without silent field guessing.

How to use

Choose or paste local input, set the explicit options, run the transformation, inspect the preview/report, then download only if the result is appropriate.

Example

The bundled fixture documents a deterministic nominal case plus malformed/boundary cases for later QA.

Formats and assumptions

CSV tools use a quote-aware parser with bounded rows/columns. Spreadsheet tools lazy-load a pinned same-origin browser runtime. Normal usage sends no file content to a server.

Limitations

The plan is explicit and name-based; duplicate output names are blocked.

Security and privacy

Processing is designed for the browser. Inputs are size-bounded. Exported spreadsheet-compatible data can carry formula-like text; the tool does not claim quoting alone neutralizes every spreadsheet application.

FAQ
