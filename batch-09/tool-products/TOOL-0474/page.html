What this tool does

Separate product value, duty, taxes and freight. Calculate landed cost from explicit import value, tariff, freight, insurance, brokerage and a configurable local tax base; not an HS tariff lookup.

How to use

  1. Review the scope and enter exact, source-backed values.
  2. Run the calculation or generate the draft locally.
  3. Read assumptions and export for a second check.

Worked example

Sample inputs: Country of origin: Country of origin (verify), Destination customs territory: Destination country (verify), Entered customs-assessable goods value: 1000. The worked reference metric is Modeled import duty: $100.00. This is a deterministic example, not a runtime-tested result.

Supported formats and units

%, currency, explicit choice, up to 100 characters. Numeric fields must be finite and within the displayed bounds. Lists and dates are checked for structure and plausible ranges.

Assumptions and known limitations

Government tariff rates change rapidly; this is not a binding tariff determination.

FAQ: Is the output authoritative?

The result is not professional certification; the source inputs and governing rules control the decision.
