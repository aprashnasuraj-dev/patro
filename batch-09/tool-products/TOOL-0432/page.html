How to use

  1. Enter the scenario values shown in the form.

Supported input formats and units

numbers / choices, %, structured JSON. Dates use the Gregorian YYYY-MM-DD civil-date format. Only listed input ranges are supported.

Assumptions and limitations

Amenity values are subjective; enforceability and shared utilities are not determined. Data is calculated locally and not uploaded.
