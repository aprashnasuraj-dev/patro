TRIR/DART Calculator with BLS Industry Benchmarks

Compute annual incident rates per 100 full-time equivalent workers from reported cases and actual employee hours; compare only to the identified BLS baseline.

What this tool does

Separate total-recordable and DART rates with a documented benchmark. Compute annual incident rates per 100 full-time equivalent workers from reported cases and actual employee hours; compare only to the identified BLS baseline.

How to use

  1. Review the scope and enter exact, source-backed values.
  2. Run the calculation or generate the draft locally.
  3. Read assumptions and export for a second check.

Worked example

Sample inputs: Employee hours actually worked in period: 200000, OSHA total recordable cases: 5, Cases with days away, restrictions or transfers: 3. The worked reference metric is TRIR per 100 FTE: 5.00. This is a deterministic example, not a runtime-tested result.

Supported formats and units

cases, explicit choice, hours, units, up to 100 characters. Numeric fields must be finite and within the displayed bounds. Lists and dates are checked for structure and plausible ranges.

Assumptions and known limitations

The 2024 aggregate benchmark is not an industry-specific classification. Latest released year and NAICS breakdown must be reviewed for publication.

FAQ: Is the output authoritative?

The result is not professional certification; the source inputs and governing rules control the decision.
