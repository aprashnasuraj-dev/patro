# Deferred acceptance matrix — do NOT execute during staging

- Known-answer independent formula cross-check with published example or hand calculation
- Min/max, integer-only cases, invalid text and non-finite quantities
- Wrong-unit plausibility, unsupported input and uncertainty banners
- Test copied CSV/clipboard, blocked clipboard, exported filename, escaping of formula-like data
- Keyboard navigation, form labeling, live result announcements, visible focus and reduced motion
- At 320px width test scrolling tables without side scrolling main page
- Reject oversize input, HTML injection and pathological loops; keep user data local
- Run relevant timer timing accuracy, visibility-pause and cancellation checks (if timer tool)
- Confirm no extra network requests, analytics of inputs, or Worker invocations
- Run Vite TypeScript build + route-level preview and check all public URLs only after QA gates
