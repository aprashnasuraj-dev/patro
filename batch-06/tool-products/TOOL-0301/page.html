Business Days Calculator with Custom Holidays and Weekends

Count working days across a date range with explicit inclusive endpoints, configurable weekend weekdays, and a private pasted holiday list.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It classifies each in-range civil date as a business day, configured weekend, custom holiday or excluded endpoint. A holiday falling on a weekend is not double-subtracted.

How to use it

Choose the range and endpoint convention, enter weekend weekday numbers, and paste any organization-specific holidays. Run the count and inspect the audit rows.

Worked example

For Monday 2 November through Friday 13 November 2026, Saturday/Sunday weekends and one Thursday holiday produce 9 business days when both endpoints are included.

Supported formats

Gregorian YYYY-MM-DD dates. Weekend values use JavaScript weekday numbering: Sunday 0 through Saturday 6. Holiday input is newline-separated YYYY-MM-DD.

Assumptions

There is no built-in national holiday dataset; the user-supplied list is authoritative for this calculation.

Limitations

The result is not a jurisdictional holiday calendar and does not infer observed/substitute holidays.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
