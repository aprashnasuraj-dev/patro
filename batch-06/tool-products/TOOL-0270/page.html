What this tool does

Estimate resistive voltage drop for a selected AWG, material, current, one-way length and circuit type while keeping ampacity and code sizing explicitly out of scope.

How to use it

Enter measured project values, review any product or code assumptions, then use the primary calculation action. Inputs are processed in the browser and bounded before calculation.

Worked example

For 12 AWG copper carrying 15 A over a 100 ft one-way run, the tool calculates conductor resistance at the entered temperature and reports volts and percentage drop.

Supported formats and units

Inputs are explicitly labeled. Unit conversions use exact SI/customary conversion factors where applicable; product coverage values remain user-configurable.

Assumptions

AWG diameter is derived from the standard AWG geometric progression; resistance is ρL/A with a linear temperature correction. Single-phase/DC uses round-trip length; balanced three-phase uses √3× one-way resistance.

Limitations

Do not use this output to select conductor ampacity, breaker size or legal installation. Reactance, harmonics, power factor, terminations and parallel conductors are not modeled.

FAQ

Does this send project data to a server?

No during normal use. The production intent is browser-side execution with no account or upload.

Can this replace a code-compliant design or product takeoff?

No. Where structure, electrical safety, HVAC sizing, jurisdiction rules or manufacturer coverage matter, the tool exposes assumptions and warnings rather than claiming approval.
