Shift Rotation Calendar Generator (Panama, 4-on-4-off)

Generate a bounded on/off rotation calendar from common 4-on-4-off or Panama/2-2-3 presets, or a custom cycle, with CSV and all-day ICS export.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It repeats one explicit on/off cycle from a chosen anchor date. The “Panama” preset is a one-crew 14-day 2-2-3 on/off sequence; day/night rotation is intentionally not inferred.

How to use it

Pick an anchor date, preset or custom O/X pattern, phase offset and generation length. Export CSV or all-day ICS work events.

Worked example

The 4-on-4-off preset generates four Work days followed by four Off days, then repeats. The Panama preset generates O,O,X,X,O,O,O,X,X,O,O,X,X,X.

Supported formats

Gregorian start date, 1–366 generated days, O/X custom pattern up to 64 entries, optional phase offset.

Assumptions

Preset names vary by employer. This tool defines exactly what its preset sequence means and does not infer 12-hour start times or crew swaps.

Limitations

Employment agreements, fatigue rules, night/day handovers and overtime are outside scope. ICS export creates all-day “Work shift” markers only.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
