Results and explanation

    How this planner works

    For regular weeks volume←previous×(1+growth/100); every cutback week volume←previous×(1−drop/100). No automatic rebound spike.

    Worked example

    Start with the sample values above, press Calculate, and compare the displayed result with the described method. Results use the units shown next to each input.
