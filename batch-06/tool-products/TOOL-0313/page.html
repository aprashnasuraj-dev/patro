Bikram Sambat (Nepali) to AD Date Converter

Standalone adapter for the project’s validated Bikram Sambat civil-date dataset, with trust-tier metadata and no fabricated arithmetic approximation.

Dataset-backed conversion: This tool reuses AafnaiPatro’s validated local BS month-length implementation. It does not use a “+56/57 years” approximation.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

The prepared core walks an injected year-by-year month-length table from a known BS↔AD anchor and returns the dataset’s trust tier with the converted date.

How to use it

Enter a supported BS date and convert it locally. The converter reuses the same validated project calendar implementation used by AafnaiPatro.

Worked example

BS 2083-01-01 maps to AD 2026-04-14 using the validated project month table.

Supported formats

BS year/month/day fields. This browser adapter uses the validated core table for BS 1970 through 2093; later provisional core rows are not exposed as validated results here.

Assumptions

No arithmetic year-offset formula is used. Month lengths come from the project’s tabulated, cross-checked BS calendar core.

Limitations

Validated browser conversion currently covers BS 1970–2093. Earlier historical exploration tiers in the wider platform are deliberately not presented by this standalone adapter as validated civil-date results.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
