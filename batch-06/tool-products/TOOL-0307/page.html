Mission Mangal · TOOL-0307

ICS Calendar File Viewer and Converter to CSV

Inspect up to 5,000 VEVENT components from pasted or locally selected ICS text, unfold RFC 5545 content lines, and export a spreadsheet-safe CSV without recurrence expansion.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It unfolds folded ICS lines, extracts a safe bounded subset of VEVENT fields and creates CSV. It does not execute or render HTML from event text.

How to use it

Paste ICS text or optionally select a local file. The file is read with File.text() in the browser; it is not uploaded. Review the event table and download CSV.

Worked example

An event with SUMMARY:Hello\, world is decoded to “Hello, world” and exported as a quoted CSV field when needed.

Supported formats

ICS/iCalendar text up to 2 MB and 5,000 VEVENT components. CSV output includes summary, start/end values, TZID, location, RRULE, UID and description.

Assumptions

VEVENT extraction is component-level. DTSTART/DTEND strings are preserved rather than silently converting unknown VTIMEZONE definitions.

Limitations

Recurrences are not expanded. Complex parameter quoting, custom components and non-VEVENT data are not converted. Use a standards-complete calendar library for round-trip editing.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
