Hijri to Gregorian Date Converter

Convert a Hijri date by explicitly choosing a browser-supported Islamic calendar variant, making civil/tabular, generic and Umm al-Qura results distinguishable.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It searches Gregorian days around the expected year and asks Intl.DateTimeFormat to label each date using the selected Islamic calendar until the requested Hijri date matches.

How to use it

Choose the Hijri year/month/day and, critically, the calendar variant. The result names that variant so a civil date cannot be mistaken for an observed or Umm al-Qura date.

Worked example

The same AH month/day can differ between islamic-civil and islamic-umalqura. The tool intentionally shows the selected variant alongside the Gregorian result.

Supported formats

Positive AH year, month 1–12, day 1–30; calendar variants islamic-civil, islamic-umalqura and generic islamic where supported by the browser.

Assumptions

Runtime ICU/CLDR is the conversion engine. The Gregorian search uses UTC dates to avoid local time-zone rollover.

Limitations

Religious observance may be based on local moon sighting and can differ by one or more days. Generic “islamic” is explicitly not a named algorithmic variant.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
