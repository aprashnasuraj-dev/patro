Bulk Epoch Timestamp Converter for Log Lines

Extract integer Unix-style timestamps from pasted log lines, auto-detect seconds/milliseconds/microseconds/nanoseconds by magnitude, and convert them without losing integer precision.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It uses BigInt for source integers so 16–19 digit micro/nanosecond values are not rounded before conversion.

How to use it

Paste logs, choose an explicit unit or auto-detection, and set a match cap. The tool extracts bounded standalone integer timestamps and exports the conversion table.

Worked example

Unix epoch 0 seconds maps to 1970-01-01T00:00:00.000Z. A 13-digit value is treated as milliseconds in auto mode.

Supported formats

Signed 9–19 digit integers. Explicit seconds, milliseconds, microseconds and nanoseconds are supported; auto mode is a magnitude heuristic.

Assumptions

“Epoch” means Unix-style time relative to 1970-01-01T00:00:00Z, ignoring leap seconds. Auto-detection is intentionally labeled heuristic.

Limitations

Logs can contain unrelated large integers. Use explicit unit mode when magnitude alone is ambiguous. JavaScript Date output is limited to its representable millisecond range.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
