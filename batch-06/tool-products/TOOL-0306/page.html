ICS Calendar File Generator with Recurrence and Alarms

Generate a bounded RFC 5545 VEVENT with escaped text, folded CRLF content lines, optional recurrence and display alarm, entirely in the browser.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It produces one RFC 5545 calendar object with a VEVENT, escaped text values, CRLF line endings, line folding, optional COUNT-bounded recurrence and DISPLAY alarm.

How to use it

Enter event details and an IANA time zone. The local wall time is first validated against DST gaps/overlaps; then download the generated text/calendar file.

Worked example

A 09:00 Kathmandu review lasting 60 minutes with a 15-minute alarm becomes DTSTART/DTEND fields tagged with Asia/Kathmandu and a VALARM trigger of -PT15M.

Supported formats

RFC 5545 text/calendar output. Recurrence is intentionally limited to FREQ=DAILY/WEEKLY/MONTHLY/YEARLY with COUNT.

Assumptions

IANA TZID values are emitted without generating a VTIMEZONE component. This matches common client practice but is not maximal standalone time-zone portability.

Limitations

This is a bounded generator, not a complete iCalendar authoring suite. Attendees, ORGANIZER, exceptions, RDATE/EXDATE and arbitrary RRULE parts are not implemented.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
