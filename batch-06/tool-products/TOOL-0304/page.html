Mission Mangal · TOOL-0304

DST Transition Dates Finder by Time Zone

Find offset changes for an IANA time zone by scanning the browser’s time-zone implementation and binary-searching each detected transition to minute precision.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It detects actual UTC-offset changes exposed by the user agent rather than applying hard-coded “second Sunday” rules that fail globally.

How to use it

Enter a year and IANA zone. The scan samples offsets every six hours and binary-searches detected changes down to roughly one minute.

Worked example

For America/New_York, a current browser normally reveals two annual offset changes. Zones such as Asia/Kathmandu should report none.

Supported formats

IANA time-zone identifier plus a Gregorian year from 1970 through 2100.

Assumptions

The browser’s Intl implementation is the runtime authority. The scan targets civil offset changes, not a semantic label of “DST” versus other legal offset reforms.

Limitations

The tool cannot report the browser’s exact tzdb release. Upstream IANA 2026e may be newer than the data embedded in a user agent.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
