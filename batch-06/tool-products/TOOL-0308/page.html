Mission Mangal · TOOL-0308

RRULE Generator with Occurrence Preview

Build a conservative RFC 5545 recurrence rule and preview bounded calendar occurrences, with invalid monthly dates skipped rather than clamped.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It creates a simple RRULE and previews the same bounded subset locally. Monthly/yearly dates that do not exist are skipped, matching recurrence semantics better than silently clamping.

How to use it

Choose DTSTART date, FREQ, INTERVAL and COUNT. Optional BYDAY is supported for WEEKLY; optional BYMONTHDAY is supported for MONTHLY.

Worked example

A monthly recurrence starting on 31 January skips February, April and June when no day 31 exists, instead of moving those occurrences to month end.

Supported formats

FREQ=DAILY/WEEKLY/MONTHLY/YEARLY, INTERVAL, COUNT, WEEKLY BYDAY and MONTHLY BYMONTHDAY. Preview is date-only.

Assumptions

The generator deliberately implements a small RFC 5545 subset whose behavior can be inspected and tested.

Limitations

It does not implement BYSETPOS, BYMONTH, BYWEEKNO, BYYEARDAY, WKST, UNTIL, EXDATE/RDATE or full RFC recurrence-set interactions.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
