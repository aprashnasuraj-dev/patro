ISO 8601 Duration Builder and Parser

Build and parse a conservative ISO 8601 duration subset, preserving years and months as calendar components instead of pretending they have fixed seconds.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It distinguishes calendar components (years/months) from fixed-duration components rather than multiplying everything by average month/year lengths.

How to use it

Paste a supported duration to parse it, or enter components to build one. The result explains whether an exact second count is meaningful without a reference date.

Worked example

P2W is exactly 1,209,600 seconds under a 7×24-hour convention. P1M is not assigned a fixed second count because February and March have different lengths.

Supported formats

Conservative ISO 8601 subset: PnYnMnDTnHnMnS and week-only PnW. Decimal seconds are supported; other fractional components are rejected.

Assumptions

The builder uses non-negative durations and integers for all components except seconds.

Limitations

This is not the complete ISO 8601 grammar. It does not support negative durations, fractional years/months/days, combined week notation, or recurring intervals.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
