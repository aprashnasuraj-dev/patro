What this tool does

Calculate board feet for sawn lumber from nominal or measured thickness, width, length and quantity, with cubic-volume cross-checks.

How to use it

Enter measured project values, review any product or code assumptions, then use the primary calculation action. Inputs are processed in the browser and bounded before calculation.

Worked example

Ten pieces of 2×8 lumber at 12 ft each equal 160 board feet before any waste allowance.

Supported formats and units

Inputs are explicitly labeled. Unit conversions use exact SI/customary conversion factors where applicable; product coverage values remain user-configurable.

Assumptions

A board foot is 144 in³; for dimensions in inches/inches/feet, board feet per piece = thickness × width × length ÷ 12.

Limitations

This is sawn-lumber volume, not a log-scaling rule and not a structural capacity calculation. Nominal and actual lumber dimensions can differ.

FAQ

Does this send project data to a server?

No during normal use. The production intent is browser-side execution with no account or upload.

Can this replace a code-compliant design or product takeoff?

No. Where structure, electrical safety, HVAC sizing, jurisdiction rules or manufacturer coverage matter, the tool exposes assumptions and warnings rather than claiming approval.
