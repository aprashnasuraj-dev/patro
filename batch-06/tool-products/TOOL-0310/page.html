ISO Week Number Calculator and Calendar

Calculate ISO week-year, week number and weekday for a Gregorian date, then list every ISO week in the selected ISO week-year with Monday/Sunday boundaries.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It applies ISO week-date rules: weeks begin Monday and week 1 is the week containing 4 January (equivalently the first Thursday).

How to use it

Choose a date and run the tool. The result highlights its ISO week and can show all 52 or 53 week ranges in that ISO week-year.

Worked example

1 January 2021 belongs to ISO week 53 of ISO week-year 2020, which demonstrates why ISO week-year can differ from calendar year near New Year.

Supported formats

Gregorian YYYY-MM-DD input; ISO week output is week-year + two-digit week conceptually, with Monday=1 through Sunday=7.

Assumptions

The implementation uses the proleptic Gregorian calendar for the selected date and ISO Monday-based week arithmetic.

Limitations

This is ISO week numbering, not locale-specific week-of-year schemes used by some payroll or calendar systems.

FAQ

Does normal use transmit my data?

No. The production intent is browser-side processing with no account, worker call or third-party transmission.

How are ambiguous dates or times handled?

The tool exposes the relevant convention, calendar variant, time zone or clamping rule and returns an explicit warning or error when a silent guess would be misleading.
