LED Resistor Calculator with Series and Parallel Arrays

Size a current-limiting resistor for LED series strings and parallel arrays, including dissipation and an E24 suggestion.

Result

Enter values and run the tool.

What this tool does

Calculates resistor value from supply headroom and target current, then rounds upward to a standard E24 value.

How to use it

Enter supply voltage, LED forward voltage, target current, LEDs/string and parallel strings.

Worked example

12 V, 3 V LEDs, 20 mA, three LEDs/string leaves 3 V across the resistor.

Assumptions

Each parallel string has its own resistor; LED Vf is treated as the entered design value.

Limitations

LED Vf varies with temperature/current; resistor power rating needs engineering margin.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.

Authoritative references

Ohm’s law and power equations; resistor preferred values are an engineering convention.
