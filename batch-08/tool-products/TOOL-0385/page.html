Voltage Divider Calculator with Standard Resistor Values

Find practical E24/E96 resistor pairs for a target voltage divider, optionally accounting for load resistance.

Result

Enter values and run the tool.

What this tool does

Searches standard resistor pairs and evaluates loaded divider output.

How to use it

Enter Vin, target Vout, preferred-value series and optional load resistance.

Worked example

5 V to 3.3 V with a high-impedance load returns a near-target E96 pair.

Assumptions

Load is modeled as parallel with R2.

Limitations

Source resistance, ADC sampling dynamics, resistor tolerance/noise and power derating are not optimized.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.

Authoritative references

Voltage-divider equation derived from Ohm’s law.
