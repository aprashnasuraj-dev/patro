What this tool does

Searches classic AVR prescalers for the lowest frequency error.

How to use it

Choose timer width, clock, target frequency and counting mode.

Worked example

16 MHz to 1 kHz Fast PWM returns a prescaler/TOP combination with near-zero error.

Assumptions

Fast PWM uses fclk/(N·(TOP+1)); phase/frequency-correct uses fclk/(2·N·TOP).

Limitations

Register names, TOP sources and available modes differ by MCU; confirm against the exact datasheet.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.
