Cups to Grams Converter by Ingredient

Convert cups to grams using ingredient-specific reference weights, with every density value editable.

Kitchen volume-to-mass values vary by packing, brand and technique. The reference value is always editable.

Result

Enter values and run the tool.

What this tool does

Multiplies cups by grams-per-cup for the selected ingredient.

How to use it

Pick an ingredient, verify/edit its grams-per-cup value, then enter cups.

Worked example

1 cup all-purpose flour → 120 g using the King Arthur reference chart.

Assumptions

Preset values are kitchen references, not physical constants.

Limitations

Packing, humidity, brand, grind and measuring technique can materially change mass.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.

Authoritative references
