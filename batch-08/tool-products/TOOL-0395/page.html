Baker's Percentage Calculator

Calculate baker's percentages from ingredient weights with flour normalized to 100%.

Result

Enter values and run the tool.

What this tool does

Sums flour lines, then expresses every ingredient weight as a percentage of total flour.

How to use it

Enter ingredient: grams, with one or more lines containing “flour”.

Worked example

500 g flour and 325 g water → 65% hydration.

Assumptions

All flour-containing lines are included in the flour basis.

Limitations

Preferments need decomposition into flour/water if you want overall baker’s percentages.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.
