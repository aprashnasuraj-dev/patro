STL Volume and Weight Estimator

Compute STL mesh volume, surface area, bounding box, and material-weight estimate locally.

Result

Enter values and run the tool.

What this tool does

Parses binary or ASCII STL triangles and integrates signed tetrahedron volumes.

How to use it

Choose an STL, declare the file’s unit, density and effective material percentage.

Worked example

A watertight 10 mm cube should be about 1 cm³.

Assumptions

Mesh is assumed watertight and consistently oriented; absolute signed volume is reported.

Limitations

STL carries no standard unit metadata. Non-manifold/open meshes can yield misleading volume.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.

Authoritative references

Library of Congress STL format descriptions.
