Pizza Dough Calculator (Hydration, Yeast, Fermentation Time)

Build pizza dough by baker percentages and optionally use a clearly labeled time/temperature yeast planning heuristic.

Optional yeast planning heuristic

This is a transparent heuristic for planning, not a safety or fermentation guarantee. Flour, yeast strain, salt, handling and refrigeration change outcomes.

Result

Enter values and run the tool.

What this tool does

Solves ingredient weights from desired dough-ball count/weight and baker percentages.

How to use it

Set balls, ball weight, hydration, salt, oil and yeast percentage.

Worked example

Four 260 g balls at 65% hydration produce a 1040 g dough total.

Assumptions

Core formula is exact baker math; the optional yeast suggestion is heuristic.

Limitations

Fermentation outcome depends on yeast strain, flour, salt, refrigeration, handling and dough temperature; use food-safe handling practices.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.

Authoritative references

Baker’s-percentage reference from King Arthur Baking; no universal yeast-time law is claimed.
