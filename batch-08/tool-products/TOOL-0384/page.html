Capacitor Code Decoder (104, 473, and Tolerance Letters)

Decode common three-digit capacitor codes and tolerance letters into pF, nF, and µF.

Result

Enter values and run the tool.

What this tool does

Interprets the first two digits as significant figures and the third as the pF power-of-ten multiplier.

How to use it

Enter e.g. 104K or 473J.

Worked example

104K → 100,000 pF = 100 nF = 0.1 µF, ±10%.

Assumptions

Common tolerance letters are supported.

Limitations

Voltage rating, dielectric, polarity, package code and manufacturer-specific markings are not inferred.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.

Authoritative references

Common passive-component marking convention.
