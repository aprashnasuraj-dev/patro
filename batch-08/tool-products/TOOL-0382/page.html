Mission Mangal · TOOL-0382

SMD Resistor Code Decoder (3-Digit, 4-Digit, EIA-96)

Decode 3-digit, 4-digit, R-decimal and EIA-96 SMD resistor markings locally.

EIA-96 uses numeric value code 01–96 plus a multiplier letter. Manufacturer-specific alias letters are intentionally not guessed.

Result

Enter values and run the tool.

What this tool does

Converts common chip-resistor markings to ohms.

How to use it

Enter a marking such as 472, 1001, 4R7, or 01C.

Worked example

472 → 4.7 kΩ.

Assumptions

EIA-96 numeric code maps to the 96 preferred values and a multiplier letter.

Limitations

Some manufacturers use alias letters or proprietary markings; those are intentionally not guessed.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.

Authoritative references
