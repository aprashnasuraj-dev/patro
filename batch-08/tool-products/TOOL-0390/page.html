ND Filter Exposure Calculator

Convert ND stops, filter factor, or optical density into a corrected exposure time.

Result

Enter values and run the tool.

What this tool does

Converts filter strength to stops and multiplies exposure by 2^stops.

How to use it

Enter a base shutter time and filter notation.

Worked example

1/125 s with 10 stops becomes about 8.192 s.

Assumptions

Optical density uses OD = log10(transmission factor), so stops = OD/log10(2).

Limitations

Real filters may deviate from nominal density and can introduce color shifts.

Privacy and security

Normal operation is browser-local. Values and uploaded files are not sent to a worker, account service, or third party.
