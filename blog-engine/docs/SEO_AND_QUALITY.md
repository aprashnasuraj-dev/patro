# SEO and evidence release contract (2026)
- Keep the existing production site and Facts feature unmodified; the private staging renderer emits Article or BlogPosting plus BreadcrumbList and honest Organization byline. QAPage is **not** appropriate for editor-authored single-answer pages without user-submitted alternative answers. FAQPage describes only actual visible multiple FAQs; Google discontinued FAQ rich results in May 2026, so do not promise snippets.
- 2,000 URLs require **one** ordinary sitemap, well below the sitemap protocol's 50,000 URL / 50 MB uncompressed limits. Keep sitemap-missionmangal.xml private until pages are deployed, then include an additional Sitemap line in existing robots.txt or submit through Search Console. Google's legacy anonymous ping endpoint was deprecated; never blindly ping it. lastmod must reflect real substantial changes, not every build.
- Editorial review and author details belong at /editorial-guidelines/; site should display corrections process and truthful AI-use disclosure, never fabricated individual expert credentials.
- Internal links: choose 3–5 contextually relevant **already published** pages from the ledger, or fewer when no suitable links exist; never invent anchors or force unrelated links. A hub/spoke curator decides placements before publication.
- Verify stored extract snapshots against linked claims, numbers, dates, APA authors/title/publisher/date/URL. Keyword overlap alone can flag suspicious citations but is NOT semantic fact verification. A missing match sends the item to review; source licenses and provenance must be checked.
- Embedding similarity above 0.75 triggers editorial pivot/review, not automatic deletion. Compare against all relevant accepted portfolio records and consider intent, not only cosine. Test repeated 12-token verbatim windows against stored source extracts and require licensing/quotation review of hits. Preserve legitimate proper terms and quotations.
- All provider retries are bounded, respect Retry-After where present and end blocked if no available model. The in-memory counters in current router are process-local: production distributed generation requires a transactional shared quota store (e.g. D1 with worker leases), never assume GitHub matrix processes share state.
- The proposed 50–100 article batches are workload targets, not publication guarantees. GitHub matrix generation requires idempotency, shared leases, artifact/review staging and distinct PR approval; GitHub Actions secrets must only enter trusted manually authorized execution, never fork PR checks.
