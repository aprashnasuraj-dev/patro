# Phase 8 — React/Vite integration

The 530-tool fleet uses one inventory-driven leaf adapter and the existing Aafnai advanced-tools product for discovery.

- `/advancetools/` remains the master advanced-tools dashboard.
- `/advancetools/web-tools/` and category pages are generated by the existing advanced-tools build system and load metadata only.
- Frozen individual canonicals remain unchanged.
- Opening a frozen leaf route loads the React/Vite shell and only that tool's staged runtime asset.
- Existing Patro/Nepali `/tools` routes are not mixed with this fleet.
- The build-preparation step keeps each batch page's substantive content and SEO description, binds canonical/social metadata to the frozen route, and rejects production-visible internal QA labels.

Full TypeScript/Vite/browser verification is intentionally deferred to the consolidated integration sweep requested by the operator.
