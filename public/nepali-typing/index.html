Keyboard guide, dictionary and licenses

Basic Roman keys: aa → आ, ii → ई, uu → ऊ, kh → ख, chh → छ, sh → श, ksh → क्ष, gy → ज्ञ, tr → त्र, shr → श्र. Capitals T/Th/D/Dh/N distinguish ट/ठ/ड/ढ/ण. Use x for ्.
