Model boundaries

Assumes four independent standard uncertainties in dB, root-sum-square combination and a user-chosen coverage factor. PASS if L+U ≤ T; FAIL if L-U > T; otherwise REVIEW. A real uncertainty budget must address correlations, distributions, reference changes and the contract's decision rule. This page is not a calibration instrument or normative certification method.
