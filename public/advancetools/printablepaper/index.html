Print at actual size

Downloads are vector drawings. Select actual size or 100% in your print dialog to preserve spacing. Fit-to-page changes millimetres. Printer non-printable margins can clip designs if the selected margin is too small.

Graph and dot spacing measures adjacent guides. Hex spacing is the distance between opposite flat sides. Music spacing is the distance between staff lines; handwriting spacing is the distance from upper guide to baseline.
