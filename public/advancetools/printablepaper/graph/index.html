About this graph paper

Square grid for mathematics, plans and sketches. Lines and dots are generated from your selected physical spacing. The PDF preserves vector geometry, so it does not need a high-resolution image.

Spacing conventions

Square and dot paper use the distance between adjacent guides. Hexagonal paper uses flat-to-flat distance. Music uses staff-line spacing, handwriting uses full guide height, and planner spacing sets horizontal task slots.

Printer settings

Select the matching paper size and print at 100%. Disable browser headers and footers if printing the page. Downloading the PDF gives the cleanest output.
