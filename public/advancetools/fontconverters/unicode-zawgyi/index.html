How to convert Myanmar text
  1. Select and copy the original font run from the document.
  2. Paste it above and press Convert text.
  3. Compare names, numbers and conjuncts with the original visual document.
  4. Copy the output or save a UTF-8 text file.
Example
မြန်မာ → ျမန္မာ
What this tool preserves
Conversion targets character encoding rather than page formatting. Text is processed locally, with no upload, no automatic storage and no account requirement. Keep your original document as a reference.
Limitations
For compatibility with legacy systems only. Unicode is preferable for searchable modern documents. Conversion is not guaranteed to be lossless. The plain-text importer cannot identify font runs. Ambiguous symbols and extraction errors require review.
Open-source mapping credits and license texts are listed on Methods & sources. Proprietary font binaries are not distributed.
