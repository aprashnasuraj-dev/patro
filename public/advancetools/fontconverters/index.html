Choose the original encoding

Legacy text often looks like Latin characters until the original font is applied. The converter must match that encoding; changing the display font alone does not recover Unicode text.

Paste only the text run encoded in the chosen font. Mixed English and legacy text can be ambiguous because the same ASCII characters are used for both. Plain text files are supported. PDF extraction, OCR and Word font-run detection are separate tasks.
