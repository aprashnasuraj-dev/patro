Mission Mangal · TOOL-0324

Diceware Passphrase Generator (EFF Wordlists)

Generate cryptographically random EFF Diceware passphrases from the exact 7,776-word long list once that list is vendored as a same-build static asset.

Integration blocker: Vendor the exact EFF 7,776-word long wordlist as src/wordlist.generated.js during integration; do not substitute a shorter or approximate list.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It uses cryptographic randomness to choose entries from EFF’s 6^5-indexed 7,776-word long list. Six independent selections provide about 77.5 bits of selection-space entropy.

How to use it

After the exact EFF list is vendored at build time, choose word count and separator, then generate. Dice indexes are shown for transparency.

Worked example

Six words from 7,776 possibilities produce 7,776^6 possible ordered phrases, approximately 2^77.5.

Supported formats

Exact EFF long-wordlist mapping: five dice digits 1–6 followed by one word; 7,776 unique rows.

Assumptions

The list is a build asset, not fetched from EFF during normal use. Random choices come from crypto.getRandomValues.

Limitations

The exact EFF list is not reproduced in this checkpoint. Integration must vendor the upstream list with attribution and lock its bytes before this tool can be marked source-complete.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
