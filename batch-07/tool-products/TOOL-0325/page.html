Argon2 and bcrypt Cost Benchmark on Your Device

Benchmark bounded Argon2id and bcrypt configurations on the current device using synthetic input, reporting measured latency without treating a browser benchmark as a server recommendation.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It measures actual elapsed time for bounded Argon2id and bcrypt work factors using a synthetic fixed password, so no user secret is needed.

How to use it

Choose costs and runs, then benchmark. The package lazy-loads locally bundled libraries; it never downloads them from a CDN at runtime.

Worked example

A 64 MiB, 3-pass Argon2id run and bcrypt cost 12 can differ dramatically between a phone and desktop, which is exactly why the result is measured rather than hard-coded.

Supported formats

Argon2id memory 8–256 MiB, passes 1–6, parallelism 1–4; bcrypt cost 8–16; one to five runs.

Assumptions

The host bundle provides audited argon2-browser and bcryptjs implementations. OWASP/RFC guidance is contextual, not a promise that one setting fits every application.

Limitations

Browser timers, thermal throttling, WASM/JIT state and tab scheduling affect results. Do not benchmark with a real password and do not copy browser parameters blindly into a production server.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
