Mission Mangal · TOOL-0334

PGP Public Key Inspector

Inspect an ASCII-armored OpenPGP public key block locally, parse bounded public-key/user-ID packets, validate optional armor CRC24, and compute RFC 9580 v4/v6 fingerprints without asserting trust.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It decodes public-key armor, parses packet framing, computes primary/subkey fingerprints using version-specific RFC rules, and extracts bounded User ID packets as text.

How to use it

Paste an ASCII-armored public-key block. The inspector never imports it into a trust store or contacts a key server.

Worked example

RFC 9580’s version 6 example primary key has fingerprint CB186C4F…BAD9ACC9; that value is included as a known-answer test.

Supported formats

ASCII-armored PGP PUBLIC KEY BLOCK; bounded old/new packet headers; v4 and v6 public-key fingerprints; User ID packets; optional armor CRC24.

Assumptions

Partial-body-length packets and indeterminate old-format lengths are rejected rather than ambiguously reassembled.

Limitations

Signatures are not cryptographically verified, expiration/revocation/trust are not evaluated, and secret-key armor is not accepted.

Privacy and security

Public key text stays local; the tool does not query key servers.
