Checksum File Verifier (sha256sums Parser)

Parse a bounded GNU-style SHA-256 checksum list, match expected names to user-selected local files, and stream-verify each file without uploading it.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It verifies expected SHA-256 values against files the user explicitly selects. Filename matching is exact and path traversal strings are never opened from disk automatically.

How to use it

Paste the checksum file text, select the files, and run. Missing names remain missing rather than being searched elsewhere on the device.

Worked example

A checksum entry for abc.txt with the standard SHA-256 of “abc” will match only if the selected local abc.txt has exactly those three bytes.

Supported formats

Simple GNU sha256sum-style lines: 64 hex characters, whitespace, optional binary marker *, then a literal filename. GNU backslash-escaped filename lines are rejected.

Assumptions

Selected File.name values are the only filesystem namespace available to the browser. No directories are traversed.

Limitations

This does not verify detached signatures on the checksum list; an attacker who can alter both a file and its expected hash can still produce a match.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
