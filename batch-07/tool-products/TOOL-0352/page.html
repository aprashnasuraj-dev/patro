Video Cropper for 9:16 Shorts and Reels with Safe Zones

Preview and export a local video cropped to 9:16 through a browser canvas, with adjustable horizontal focus and editable top/bottom safe-zone guides.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It computes the source rectangle needed to fill a vertical canvas, lets the user move the horizontal focal point, and records the canvas locally.

How to use it

Load a local video, inspect the crop and editable guides, adjust focus, then export. Export runs in real time.

Worked example

A 1920×1080 landscape source cropped to 9:16 uses about 607.5 source pixels of width; 50% focus centers that crop.

Supported formats

Browser-decodable local video; WebM canvas export; 30-minute/750 MiB preparation bounds.

Assumptions

Safe-zone guides are editable composition aids, not official universal overlays for every Shorts/Reels UI surface.

Limitations

Real-time export is CPU-heavy and browser-dependent. Codec/container support varies; audio preservation depends on captureStream support. It is not a frame-accurate non-linear editor.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
