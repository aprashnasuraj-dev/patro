PKCE Code Verifier and Challenge Generator

Generate RFC 7636-compliant PKCE code verifiers and S256 challenges locally with cryptographic randomness and strict verifier syntax validation.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It generates a high-entropy verifier from RFC 7636’s allowed unreserved character set and computes BASE64URL(SHA256(ASCII(verifier))) without padding.

How to use it

Generate a verifier or paste an existing one, then calculate the S256 challenge.

Worked example

RFC 7636’s published verifier dBjft…EjXk produces challenge E9Mel…w-cM; that exact pair is included as a deferred known-answer test.

Supported formats

Verifier length 43–128, characters A–Z a–z 0–9 - . _ ~; S256 challenge is unpadded base64url.

Assumptions

S256 is used; the weaker plain method is intentionally not offered.

Limitations

PKCE protects authorization-code interception in supported OAuth flows; it does not replace state/nonce validation, redirect-URI validation or secure token handling.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
