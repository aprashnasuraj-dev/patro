Assumptions

All calculations follow the explicit fields/presets shown in the UI; hidden institution/server defaults are avoided.

Limitations

Uses the first worksheet only in this source-prep version; formulas are read as displayed values and complex merged cells/styles are not reproduced.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.

Authoritative references

No external standard is required for the deterministic calculation; assumptions are documented in the tool.
