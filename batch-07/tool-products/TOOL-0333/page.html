SSH Public Key Fingerprint Calculator

Parse one OpenSSH public-key line, validate its binary type field, and compute the modern SHA256 fingerprint over the decoded key blob without including the comment.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It validates the SSH binary string that names the key algorithm before hashing the entire decoded blob with SHA-256.

How to use it

Paste a single .pub line. The comment is shown separately so it cannot be mistaken for fingerprint input.

Worked example

Changing only “user@host” after the base64 key leaves the fingerprint unchanged; changing any byte in the key blob changes it.

Supported formats

One OpenSSH public-key line: type, base64 blob, optional comment. Common RSA, ECDSA and Ed25519 blob types work as long as the outer and inner type strings match.

Assumptions

Modern SHA256 fingerprint display is used. Legacy MD5 colon-hex fingerprints are intentionally not generated.

Limitations

This does not validate whether the key is authorized, revoked, weak, or associated with a trusted host/user.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
