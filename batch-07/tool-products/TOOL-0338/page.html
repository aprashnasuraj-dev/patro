QR Code Inspector with Link Safety Hints

Decode one QR image locally using native BarcodeDetector when available or a bundled ZXing fallback, then inspect decoded text/URL structure for non-authoritative safety hints without navigating to it.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It decodes locally and then analyzes only the decoded string. URL fields are rendered as text, not activated automatically.

How to use it

Select an image, decode, inspect the exact payload and structural hints, and copy it only if needed.

Worked example

A QR containing http://user@example.com/ is flagged for HTTP and URL userinfo. The tool still does not claim example.com is malicious or safe.

Supported formats

Common image files accepted by createImageBitmap; QR Code payload text up to 20,000 characters; absolute URLs parsed by the browser URL implementation.

Assumptions

Native BarcodeDetector is preferred when QR support exists; otherwise a locally bundled ZXing browser decoder is lazy-loaded from the application bundle.

Limitations

Structural hints are not reputation scanning. Unicode look-alike detection is intentionally lightweight, not full UTS #39 confusable-skeleton analysis.

Privacy and security

The QR image and decoded payload are not uploaded or opened as a link.
