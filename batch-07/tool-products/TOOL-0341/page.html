Social Post Character Counter with Link and Emoji Weighting

Count grapheme clusters, Unicode code points, UTF-8 bytes and an X/twitter-text-v3-compatible weighted approximation where links count as 23 and many non-Latin/emoji graphemes count as two.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It shows multiple notions of “character” because social platforms can count text differently from JavaScript string length.

How to use it

Paste a post, select a counting model and editable limit, then review the weighted count and raw Unicode metrics.

Worked example

Under twitter-text v3, “Hi ” counts three and a URL contributes 23, so “Hi http://test.co” has weighted length 26.

Supported formats

Plain grapheme count or bounded X/twitter-text-v3 weighting; arbitrary editable limit.

Assumptions

The X preset uses v3 configuration values: max 280, scale 100, default weight 200, selected Unicode ranges weight 100, transformed URL length 23.

Limitations

This is not the complete upstream twitter-text URL and emoji parser. Other platforms change limits and weighting; use the editable limit rather than treating a preset as permanent.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
