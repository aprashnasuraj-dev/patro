Mission Mangal · TOOL-0329

Encrypt and Decrypt Text with a Password (AES-GCM)

Encrypt or decrypt bounded UTF-8 text locally with AES-256-GCM and PBKDF2-HMAC-SHA-256, using a versioned JSON envelope with random salt and nonce.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It derives a 256-bit key from the password and a fresh 16-byte salt, then authenticates/encrypts UTF-8 text with a fresh 96-bit AES-GCM nonce.

How to use it

Enter a password and plaintext, encrypt, then save the complete JSON envelope. To decrypt, paste the envelope and same password.

Worked example

Encrypting the same text twice produces different envelopes because salt and nonce are random; both decrypt to the original text with the same password.

Supported formats

Versioned APENC1 JSON envelope using PBKDF2-HMAC-SHA-256 and AES-256-GCM with 128-bit authentication tag.

Assumptions

PBKDF2 uses 600,000 iterations in this envelope version. The envelope records its iteration count for future compatibility.

Limitations

Password-based encryption inherits password strength. This tool has no recovery key. Losing the password loses access; changing any authenticated field causes decryption failure.

Privacy and security

Password, plaintext and ciphertext remain in the browser; none are persisted by the tool.
