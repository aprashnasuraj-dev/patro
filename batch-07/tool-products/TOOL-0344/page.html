YouTube Chapters Timestamp Formatter and Validator

Parse, normalize and validate YouTube chapter timestamps against current manual-chapter rules, with optional video-duration boundary checking.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It checks the chapter rules YouTube currently documents and emits a normalized description-ready block.

How to use it

Paste one timestamp/title pair per line, optionally enter total duration, then fix every reported rule error before copying.

Worked example

0:00 Intro, 0:45 Setup, 2:10 Demo passes the first-timestamp, three-chapter, ascending-order and 10-second rules.

Supported formats

m:ss or h:mm:ss timestamps followed by a non-empty title.

Assumptions

Duration checking is optional. The tool validates syntax and published chapter timing rules only.

Limitations

YouTube can still withhold chapter display for account/content eligibility reasons not detectable from a timestamp list.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
