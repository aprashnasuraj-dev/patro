Mission Mangal · TOOL-0351

Online Teleprompter with Mirror Mode

Run a distraction-light, browser-local teleprompter with adjustable scroll speed, font size, line spacing, mirror mode and keyboard pause/resume.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It renders the script as plain text and scrolls the local container at a predictable pixel-per-second rate.

How to use it

Paste the script, choose visual settings, start, then use the pause button or Space while the prompter is focused.

Worked example

At 45 px/s, a 450 px section of script traverses in roughly ten seconds; increasing font size changes how many words fit per screen.

Supported formats

Plain Unicode text; no rich HTML is interpreted.

Assumptions

Pixel speed is easier to keep deterministic than “words per minute” because line wrapping depends on viewport and font metrics.

Limitations

Browser full-screen behavior, external teleprompter hardware and reflected optical geometry vary; mirror mode simply flips the rendered stage.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.

Authoritative references

  • No external standard is required for this deterministic transform.
