Mission Mangal · TOOL-0328

TOTP Debugger (RFC 6238)

Debug RFC 6238 TOTP codes from a Base32 secret, timestamp, period, digit count and HMAC algorithm, including adjacent time-window counters and remaining seconds.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It implements TOTP as HOTP over floor(timestamp/period), including RFC dynamic truncation, and shows nearby counters for diagnosing clock skew.

How to use it

Paste the Base32 seed, choose algorithm/digits/period and optionally enter an exact Unix timestamp. The seed remains local.

Worked example

RFC 6238’s SHA-1 test secret at Unix time 59 seconds produces the 8-digit code 94287082.

Supported formats

Unpadded/padded Base32 seed (A–Z, 2–7), HMAC SHA-1/256/512, 6 or 8 digits, period 15–120 seconds.

Assumptions

T0=0. Unix time ignores leap seconds. Provisioning URI parsing is intentionally outside scope.

Limitations

This is a debugger, not an authenticator vault. It does not store secrets or enforce verifier-side throttling/replay protection.

Privacy and security

The TOTP secret is never persisted or transmitted by this package.
