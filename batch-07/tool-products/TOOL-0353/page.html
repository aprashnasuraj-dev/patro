Link-in-Bio Page Generator (Single HTML File)

Generate a self-contained, script-free link-in-bio HTML page with validated URLs, escaped text, embedded theme CSS and an optional small local avatar data URI.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It escapes all user text and accepts only http, https and mailto links, producing a static page with no JavaScript.

How to use it

Enter title/subtitle, one label|URL pair per line, optional small avatar and accent, then download the self-contained HTML.

Worked example

“Website | https://example.com” becomes a safe anchor; a javascript: URL is rejected rather than serialized.

Supported formats

1–30 links; optional PNG/JPEG/WebP avatar embedded as a data URI; one downloadable UTF-8 HTML file.

Assumptions

The generated page is intended for static hosting. HTTP(S) links can still lead anywhere the user configured.

Limitations

No analytics, custom domains, forms, remote fonts or platform hosting are included. CSP is defensive but cannot judge destination safety.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.

Authoritative references

  • No external standard is required for this deterministic transform.
