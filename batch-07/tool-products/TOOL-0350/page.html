Mission Mangal · TOOL-0350

Webcam and Microphone Test

Test camera preview, negotiated track settings, device labels and live microphone RMS/peak levels locally after explicit browser permission.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It exposes the actual video/audio track settings negotiated by the browser and a simple live waveform level meter.

How to use it

Grant camera and microphone permission, verify preview/levels/settings, then stop devices when finished.

Worked example

A browser may negotiate 1280×720 even if the camera advertises higher modes; the reported values come from the active MediaStreamTrack settings.

Supported formats

Browser camera/microphone MediaStreams; no file is created.

Assumptions

Device labels may remain blank until permission is granted. Meter values are signal amplitude, not calibrated dB SPL.

Limitations

A good browser preview does not prove meeting-app echo cancellation, network quality, hardware latency or acoustic calibration.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
