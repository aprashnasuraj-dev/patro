Screen Recorder with Webcam Overlay (No Watermark)

Record a user-selected screen/window/tab into a browser-generated WebM with optional webcam picture-in-picture and microphone/display-audio mixing, with no upload or watermark.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It composites screen and optional webcam frames into a canvas, captures that canvas as a MediaStream, optionally mixes available audio tracks, and records locally with MediaRecorder.

How to use it

Start from a secure HTTPS page, grant only the screen/camera/mic sources you intend, then stop and download the WebM.

Worked example

A 1920×1080 screen with 22% webcam size produces an overlay about 422 px wide while retaining the screen’s output dimensions.

Supported formats

WebM output using the first supported VP9/VP8/default WebM MediaRecorder type; browser-dependent display/system audio support.

Assumptions

The browser supports canvas.captureStream, MediaRecorder and screen capture. Audio mixing depends on available captured audio tracks.

Limitations

Safari/browser support and system-audio capture differ. This real-time canvas approach can drop frames on slow devices and does not promise frame-perfect editing.

Privacy and security

Capture streams remain in browser memory and the final Blob is downloaded locally; no recording is uploaded by this package.
