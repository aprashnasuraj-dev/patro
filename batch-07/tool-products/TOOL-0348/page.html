Podcast RSS Feed Validator (Paste XML)

Parse pasted podcast RSS XML locally and check a bounded Apple-oriented technical subset: RSS 2.0 root, channel metadata, artwork, required episode enclosure/GUID fields, duplicate identifiers and date syntax.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It performs local structural validation of requirements that can be verified from XML alone and clearly separates checks that require remote HTTP/media inspection.

How to use it

Paste the complete RSS XML and run. Fix blocking structural errors, then use your podcast platform’s own remote validator before submission.

Worked example

An episode with title, unique GUID, RFC-style pubDate and enclosure url/length/type passes the episode-field subset; duplicate GUIDs are flagged.

Supported formats

Well-formed RSS 2.0 XML up to 2 MB and 2,000 episode items; DTD/entity declarations are rejected.

Assumptions

Apple-oriented tags use the standard iTunes namespace. Browser Date parsing is used only as a warning heuristic.

Limitations

This cannot verify public reachability, byte-range support, actual file lengths, artwork dimensions/alpha, category validity against the live taxonomy, or final platform approval.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
