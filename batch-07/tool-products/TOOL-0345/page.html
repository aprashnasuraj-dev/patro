Accessible Hashtag Formatter (PascalCase)

Convert delimited hashtag phrases to PascalCase while preserving letters, numbers and non-Latin scripts, with warnings when an unsegmented lowercase hashtag cannot be reliably word-split.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It makes visible word boundaries in hashtags when those boundaries are supplied by spaces, underscores, hyphens or existing capitals, improving readability for many people and assistive technologies.

How to use it

Enter one phrase/hashtag per line. Review warnings for strings that contain no trustworthy word boundaries.

Worked example

#digital_accessibility becomes #DigitalAccessibility; #WorldMentalHealthDay retains its existing internal capitals.

Supported formats

Unicode letters/numbers/combining marks; delimiters include whitespace, underscore, hyphen, dot and slash.

Assumptions

The tool never guesses dictionary boundaries inside a long all-lowercase concatenation.

Limitations

PascalCase improves visual parsing but does not guarantee every screen reader will pronounce a hashtag perfectly, especially for names, acronyms or mixed scripts.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
