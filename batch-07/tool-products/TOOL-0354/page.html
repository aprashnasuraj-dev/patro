Thread Splitter for Posts (Numbered, Sentence-Aware)

Split long text into numbered social-thread parts using sentence/word boundaries, optional X-like weighted counting, and iterative suffix sizing so every emitted part stays within the selected limit.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It prefers sentence boundaries, then whitespace, and only hard-splits a token when no softer boundary can satisfy the limit.

How to use it

Choose limit/counting/numbering, split, then review each part before posting.

Worked example

Numbering reserves space for “ 1/N” before the content is split, so adding suffixes does not silently push a part over the configured limit.

Supported formats

Plain Unicode text; plain grapheme or bounded X-like weighted counting.

Assumptions

Sentence segmentation uses Intl.Segmenter when available. The X-like mode shares the bounded approximation used by the counter tool.

Limitations

Semantic continuity is not guaranteed; always review joins. Platform-specific mentions, media attachments and quote-post rules are outside this local splitter.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
