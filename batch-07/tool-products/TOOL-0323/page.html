Mission Mangal · TOOL-0323

Password Strength Auditor with Pattern Breakdown

Audit a password locally for length, repetition, sequences, keyboard walks, date/year patterns and character diversity without transmitting or persisting the secret.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It surfaces recognizable password construction patterns and a clearly labeled local heuristic score. It deliberately avoids fake “time to crack” numbers that depend heavily on attacker model and breached-password knowledge.

How to use it

Type a password, keep it masked unless you explicitly reveal it, then run the audit. Nothing is stored by the package.

Worked example

“aaaaaaaa” is flagged for repetition; a long multi-word passphrase avoids that pattern but should still be unique and checked against an organization’s compromised-password blocklist.

Supported formats

Any Unicode string up to 512 code points.

Assumptions

The heuristic is explanatory, not a formal entropy estimator. It has no breach corpus, user-specific context or attacker dictionary.

Limitations

A password can score well here and still be compromised, reused or predictable to someone who knows the user. Production verifiers should apply current NIST guidance and blocklists.

Privacy and security

The password stays in the input control and local JavaScript memory. The package does not log, save, hash for storage, or transmit it.
