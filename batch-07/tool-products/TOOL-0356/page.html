YouTube Embed Code Builder (Start Time, Privacy Mode)

Generate a sanitized YouTube iframe snippet from common YouTube URL forms, with start/end time, controls, autoplay/mute, looping and Privacy Enhanced Mode using youtube-nocookie.com.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It canonicalizes supported YouTube URL forms to a video ID and serializes only known embed parameters.

How to use it

Paste a YouTube link, set timing/playback options, choose privacy mode, and copy the generated iframe code.

Worked example

Privacy Enhanced Mode changes the embed host from youtube.com to youtube-nocookie.com. Loop mode also adds playlist=, which the embedded player requires for a single video loop.

Supported formats

youtube.com/watch, /embed, /shorts, /live; youtu.be; or a bare 11-character video ID.

Assumptions

Start/end are integer seconds. Autoplay is paired with mute to improve browser autoplay compatibility.

Limitations

Player policy, age restrictions, embedding permissions, cookies/storage and future YouTube parameters remain controlled by YouTube. Privacy Enhanced Mode is not “no network/no data.”

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
