Text-on-Image Contrast Checker (WCAG and APCA)

Measure WCAG 2.x contrast ratio and APCA lightness contrast for a chosen text color against a solid background or clicked pixels from a local image, including a small neighborhood worst-case sample.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It computes the current WCAG 2.x luminance ratio and the published APCA 0.1.7-style Lc equation separately, then can sample image pixels around a click.

How to use it

Choose text color and either a solid background or local image. For an image, click representative positions, especially the lowest-contrast areas behind the text.

Worked example

Black on white produces the maximum 21:1 WCAG ratio. APCA uses a different signed perceptual scale and should not be compared numerically to 4.5:1.

Supported formats

Opaque sRGB hex colors and browser-decodable images.

Assumptions

Image pixels are sampled from browser-decoded sRGB-like canvas data. Font size/weight is not automatically inferred.

Limitations

A single pixel/neighborhood does not prove contrast across an entire text bounding box or dynamic image/video. APCA remains evolving guidance; current WCAG 2.x conformance uses WCAG ratios.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
