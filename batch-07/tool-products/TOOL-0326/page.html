HMAC Generator and Webhook Signature Tester

Generate or verify HMAC-SHA-256/384/512 signatures with explicit key and signature encodings using native Web Crypto, suitable for debugging webhook signing conventions locally.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It computes an HMAC over the exact UTF-8 payload bytes and can compare an expected signature after removing common sha256=/sha384=/sha512= prefixes.

How to use it

Choose hash/key encoding/output encoding, paste the secret and exact raw payload, optionally paste the expected signature, then generate/verify.

Worked example

The prepared fixture includes the standard HMAC-SHA-256 “Hi There” vector with a 20-byte 0x0b key.

Supported formats

HMAC SHA-256, SHA-384 or SHA-512; key as UTF-8, hex or base64; signature as hex or unpadded base64url.

Assumptions

Payload text is UTF-8 encoded exactly as shown. No JSON canonicalization or newline normalization is performed.

Limitations

A correct HMAC can still fail a webhook check if the provider signs a timestamp prefix, raw HTTP body bytes or another framing convention. Consult that provider’s specification.

Privacy and security

Secret and payload remain browser-local and are not persisted.
