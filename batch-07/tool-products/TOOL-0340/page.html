Subresource Integrity (SRI) Hash Generator

Generate W3C Subresource Integrity metadata for local files or pasted resource text using SHA-256, SHA-384 and SHA-512 without uploading the resource.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It hashes the exact local bytes and formats base64 digests with the SRI algorithm token expected by browsers.

How to use it

Choose a file or paste exact text, select algorithms, add the deployment URL, then copy the generated integrity attribute/snippet.

Worked example

The UTF-8 bytes for “hello” produce SHA-256 SRI metadata sha256-LPJNul+wow4m6DsqxbninhsWHlwfp0JecwQzYpOLmCQ=.

Supported formats

SHA-256, SHA-384 and SHA-512 integrity metadata for script or stylesheet snippets.

Assumptions

Pasted text is UTF-8 encoded. A file is hashed as raw bytes. The deployment resource must be byte-for-byte identical.

Limitations

SRI does not make a compromised first-party page trustworthy and cross-origin integrity-protected requests can require compatible CORS headers.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
