PEM to JWK and JWK to PEM Converter

Convert RSA or EC public/private key material between JWK and standard SPKI/PKCS#8 PEM containers using native Web Crypto with explicit curve/container choices.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It uses Web Crypto imports/exports to validate key structures while converting, rather than merely rewrapping arbitrary base64 text.

How to use it

Choose direction, expected key family and public/private container, paste the key, and convert.

Worked example

A PUBLIC KEY PEM containing RSA SubjectPublicKeyInfo becomes a JWK with kty RSA, n and e. A private EC JWK with d can become PKCS#8 PRIVATE KEY PEM.

Supported formats

RSA and EC P-256/P-384; JWK; SPKI PUBLIC KEY PEM; PKCS#8 PRIVATE KEY PEM.

Assumptions

RSA keys are imported through RSA-OAEP/SHA-256 and EC keys through ECDSA solely to validate/export their generic key material.

Limitations

Encrypted private-key PEM, PKCS#1 “RSA PRIVATE KEY”, SEC1 “EC PRIVATE KEY”, X.509 certificates and unsupported curves are intentionally rejected.

Privacy and security

Key material remains local; private-key input is not saved or transmitted.
