Verifiable Random Giveaway Picker

Run a reproducible giveaway draw using a commit/reveal secret, canonical participant-list hash and deterministic SHA-256-based unbiased shuffle, producing a downloadable audit record.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It separates a pre-draw commitment from the revealed secret, hashes the exact canonical participant list, and uses deterministic rejection-sampled Fisher–Yates selection.

How to use it

Before entries close, generate a secret and publish only the commitment. After the final list is frozen, reveal the secret, draw, and publish the audit JSON.

Worked example

Anyone with the same ordered participant list and revealed secret can recompute the list hash, seed hash and winners; changing the secret breaks the earlier commitment.

Supported formats

2–10,000 participant lines; 1–100 winners; exact-name de-duplication optional.

Assumptions

Fairness depends on publishing the commitment before the organizer knows the final draw outcome and freezing the participant-list ordering.

Limitations

This proves reproducibility, not that entrants were eligible or the organizer committed at the claimed time. Stronger public lotteries may combine independent external randomness after entries close.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
