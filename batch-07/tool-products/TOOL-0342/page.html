Instagram Carousel and Grid Image Splitter

Split one local image into an exact rows-by-columns grid or horizontal carousel, preserving pixel order and exporting individually numbered PNG/JPEG tiles entirely in the browser.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It divides original pixel boundaries deterministically, including dimensions that are not evenly divisible, so no pixel rows/columns disappear.

How to use it

Select an image, choose grid dimensions and output format, then download numbered tiles in posting order.

Worked example

A 3000×1000 image split into three columns yields three 1000×1000 tiles.

Supported formats

Browser-decodable image inputs; PNG or JPEG tile outputs; maximum 50 tiles.

Assumptions

The image has already been designed at a useful aspect ratio for the intended social surface. The splitter does not add carousel continuity padding.

Limitations

Platform upload limits, cropping and carousel behavior can change. Very large decoded images are rejected to protect browser memory.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.

Authoritative references

  • No external standard is required for this deterministic transform.
