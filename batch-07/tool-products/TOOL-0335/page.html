API Key and Token Generator (Hex, Base62, UUIDv7, ULID)

Generate batches of cryptographically random hex/Base62 secrets plus UUIDv7 and ULID identifiers, with exact entropy accounting for the random portion and unbiased Base62 sampling.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It uses crypto.getRandomValues and rejection sampling for Base62 so modulo bias is avoided. UUIDv7 and ULID include timestamps, so only their random portion is counted as secret entropy.

How to use it

Choose format, length/count and optional visible prefix. Treat UUID/ULID primarily as identifiers; use hex/Base62 with sufficient random bits for secrets.

Worked example

A 32-character hex secret contains 16 random bytes = 128 random bits. A 32-character Base62 secret contains about 190.5 random bits.

Supported formats

Hex, Base62, UUIDv7 and canonical 26-character ULID; batches up to 1,000.

Assumptions

The browser CSPRNG is available. Prefix text is public and contributes zero secret entropy.

Limitations

UUIDv7 and ULID expose creation time and are not designed to hide timing metadata. API keys also need safe storage, rotation, scope and server-side verification.

Privacy and security

Generated secrets are never persisted or transmitted by this package.
