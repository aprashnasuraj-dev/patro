UUID v4/v7 and ULID Generator with Timestamp Decoder

Generate UUIDv4, RFC 9562 UUIDv7 or ULID values and decode embedded timestamps from UUIDv7/ULID with strict version/variant and Crockford Base32 validation.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It creates identifiers with a browser CSPRNG and decodes only the timestamp-bearing formats with strict canonical syntax checks.

How to use it

Generate batches, or paste one UUIDv7/ULID into the decoder to recover its millisecond timestamp.

Worked example

UUIDv7 stores Unix milliseconds in the first 48 bits; ULID stores the same-width timestamp in its first 10 Crockford Base32 characters.

Supported formats

Canonical lowercase/uppercase-insensitive UUIDv7 with hyphens; canonical 26-character ULID alphabet; generated UUIDv4.

Assumptions

UUIDv7 generation uses random bits rather than an optional monotonic sub-millisecond field. ULID generation is random within a millisecond, not monotonic.

Limitations

Generation order within the same millisecond is not guaranteed to sort monotonically. Timestamp-bearing IDs reveal approximate creation time.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
