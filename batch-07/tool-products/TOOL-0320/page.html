Mission Mangal · TOOL-0320

Moon Phase Calculator for Any Date

Estimate lunar phase angle, illuminated fraction and lunar age for any UTC instant using a transparent low-precision local solar/lunar longitude model.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It estimates the Moon–Sun ecliptic longitude separation, converts that to illuminated fraction and lunar age, and names the familiar eight-phase region.

How to use it

Enter a UTC date/time. The calculation stays local and returns a numeric phase angle rather than only a decorative phase name.

Worked example

A phase angle near 0° is New Moon, near 90° First Quarter, near 180° Full Moon and near 270° Last Quarter.

Supported formats

Gregorian UTC date/time. Output illumination is 0–100%, phase angle 0–360° and age approximately 0–29.53 days.

Assumptions

A truncated low-precision geocentric longitude model is used. Topocentric parallax and high-order perturbations are omitted.

Limitations

Do not use this estimate for occultations, eclipse prediction, precise moonrise/set or ritual/legal determinations that depend on local observation.

Privacy and security

Normal use is browser-local. Inputs are not sent to a worker, account service, or third party by this tool.
