RSA and ECDSA Key Pair Generator (PEM and JWK)

Generate exportable RSA or ECDSA key pairs with native Web Crypto and show public/private PEM plus JWK representations without transmitting the private key.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It delegates key generation to the browser’s cryptographic implementation and exports standards-compatible SubjectPublicKeyInfo/PKCS#8 DER wrapped in PEM, plus JWK.

How to use it

Choose RSA-OAEP or an ECDSA curve, generate, copy only what you need, and protect private material carefully.

Worked example

RSA 3072 generates an exponent 65537 key pair. ECDSA P-256 generates EC JWK x/y coordinates and private d for the private JWK.

Supported formats

RSA-OAEP 3072/4096 with SHA-256; ECDSA P-256/P-384; PEM PUBLIC KEY/PRIVATE KEY; JWK.

Assumptions

RSA purpose is OAEP encryption; EC purpose is ECDSA signing. The resulting underlying key material can only be used compatibly with algorithms accepted by the destination system.

Limitations

Web Crypto algorithm labels/purposes matter. This is not a certificate generator, SSH key generator or OpenPGP key generator.

Privacy and security

Private key material is generated and exported only in the browser. It is hidden by default and never persisted by this tool.
