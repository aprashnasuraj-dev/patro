Office Document Metadata Scrubber (DOCX, XLSX, PPTX)

Scrub common OOXML document-property fields from DOCX/XLSX/PPTX locally after preflighting ZIP entry counts, uncompressed size and compression ratio to reduce ZIP-bomb risk.

Result

Use the sample state or enter your values, then run the tool.

What this tool does

It preflights the ZIP central directory, then rewrites common core/app/custom document-property fields while preserving the OOXML package structure.

How to use it

Select a DOCX/XLSX/PPTX, scrub, review which property parts changed, and download a new copy. The original file is untouched.

Worked example

A DOCX with dc:creator and cp:lastModifiedBy retains its document content but those targeted property values are blank in docProps/core.xml.

Supported formats

OOXML ZIP packages DOCX/XLSX/PPTX; non-ZIP legacy DOC/XLS/PPT are unsupported.

Assumptions

The host build bundles fflate locally. ZIP64 is intentionally rejected by the preflight parser.

Limitations

Metadata can exist outside docProps. This is not a substitute for a complete hidden-content/privacy inspection, and it must never claim to remove all identifying information.

Privacy and security

Office files are read and rewritten entirely in browser memory; no upload occurs.
