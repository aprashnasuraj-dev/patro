Record stream organizer: JSONL / NDJSON to JSON Array Converter

Convert line-delimited JSON records into one JSON array without skipping malformed lines.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste line-delimited JSON objects and download the array. Review the record-count and first invalid line if rejected.

Worked example

Example input:

{"id":1,"name":"Ada"}
{"id":2,"name":"Lin"}

Choose Build JSON array to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Parsing uses a bounded in-browser string; very large NDJSON files require a streaming integration. Empty lines optionally ignored.
