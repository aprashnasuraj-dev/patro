API documentation

Turn a Postman collection into a structured API handbook

Recursive folder-aware Markdown export focusing on request metadata and endpoint structure, excluding secrets and scripts.

Designed for

Request catalog · folder hierarchy · default redaction

The local browser workspace will load when this route is activated. You can read the instructions below without JavaScript.

How to use this tool

Export a single-JSON collection in Postman v2.1 format, import it here and copy/download Markdown for review.

Worked example

Try this representative input to inspect the output and its warnings:

{"info":{"name":"Project API","schema":"https://schema.getpostman.com/json/collection/v2.1.0/collection.json"},"item":[{"name":"Accounts","item":[{"name":"List customers","request":{"method":"GET","url":"{{baseUrl}}/customers?api_key=hidden","header":[{"key":"Accept","value":"application/json"}]}}]}]}

Supported formats and constraints

Postman collection JSON v2.0/v2.1; Markdown

Postman v3 folder-based exports are not supported. Auth tokens, response examples, scripts and request bodies are intentionally omitted.

Privacy and safety

Source is prepared for local browser execution. There is no automatic upload or third-party conversion API; verify actual behavior during the post-import testing stage. Review any exported content before sharing or executing it.
