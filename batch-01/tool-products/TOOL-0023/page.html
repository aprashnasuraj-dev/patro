Job portability studio: GitLab CI to GitHub Actions Converter

Translate a narrow subset of GitLab CI jobs into a GitHub Actions draft, without executing arbitrary scripts.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste a simple script-only GitLab pipeline. Inspect unsupported features and choose explicit action permissions.

Worked example

Example input:

stages: [test]
smoke:
  stage: test
  image: node:22
  script:
    - echo hello

Choose Draft GitHub workflow to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Rules, needs, include, extends, artifacts, service containers, protected variables, environments and GitLab runners are not portable without manual migration.
