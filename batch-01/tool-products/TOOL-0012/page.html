Data profiling studio: CSV to SQL CREATE TABLE (Type-Inferred)

Profile CSV columns and generate PostgreSQL 18 DDL with conservative SQL types.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste CSV with an ordinary header. Inspect inferred columns and generated SQL before migration.

Worked example

Example input:

id,name,enabled,amount,date
1,Ada,true,2.50,2026-01-04
2,Lin,false,8.25,2026-03-05

Choose Infer SQL table to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Sample-based inference does not prove constraints or future values; defaults to nullable types and no automatically inferred primary keys. PostgreSQL DDL review required.
