Infrastructure variable editor: Terraform tfvars to JSON Converter

Convert a deliberately bounded literal HCL tfvars subset into terraform.tfvars.json.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste basic literal variable assignments and export valid JSON for tfvars.json.

Worked example

Example input:

region = "ap-south-1"
replicas = 2
enabled = true
ports = [80, 443]
tags = { owner = "infra", env = "dev" }

Choose Convert tfvars to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

HCL expressions, interpolation, function calls and complex block syntax are rejected. Comments supported; source credentials remain only in your browser.
