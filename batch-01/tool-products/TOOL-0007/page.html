HTTP debugging workflow

Turn captured HTTP traffic into reviewable curl scripts

Generates quoted POSIX commands without executing them. Authentication is removed unless intentionally reintroduced outside this tool.

Designed for

No command execution · secret-safe defaults · shell quoting

The local browser workspace will load when this route is activated. You can read the instructions below without JavaScript.

How to use this tool

Load a HAR file, choose whether to keep request bodies or query strings, generate and manually inspect the shell script.

Worked example

Try this representative input to inspect the output and its warnings:

{"log":{"version":"1.2","entries":[{"request":{"method":"GET","url":"https://example.com/api/users?api_key=TOPSECRET","headers":[{"name":"Accept","value":"application/json"},{"name":"Authorization","value":"Bearer secret"}]}}]}}

Supported formats and constraints

HAR 1.2 JSON; curl POSIX shell drafts

Security tokens, replay-order dependencies, cookies, multipart/binary bodies and browser session state are not automatically reconstructed.

Privacy and safety

Source is prepared for local browser execution. There is no automatic upload or third-party conversion API; verify actual behavior during the post-import testing stage. Review any exported content before sharing or executing it.
