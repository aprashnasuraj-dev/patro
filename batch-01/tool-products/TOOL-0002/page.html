Paste one or multiple JSON examples and generate a structural Zod validator. Compare samples to infer missing optional fields and mixed-type unions without sending data to a server.

How to use

Paste valid JSON, optionally separate up to 20 examples with ---sample---, choose a safe TypeScript identifier, then generate and copy or download the source. Empty arrays produce unknown element types.

Worked example

If one sample has {"id":1,"name":"Asha"} and another has {"id":2,"active":true}, the generated object marks name and active as optional and id as required.

Formats and limits

Input: JSON text, up to 20 samples, 256 KiB per sample, 35 levels deep and 10,000 total values. Output: Zod v4 TypeScript source. This infers observed structure, not business constraints, UUIDs, dates, regexes, minimums or schemas that guarantee all future data.

Security and privacy

Conversion is intended to run locally; no user JSON is sent to an API by the tool. The generated source should be reviewed before use for untrusted production payloads. This is staged source, not a tested or published product.

Authority

Syntax follows Zod schema documentation and Zod 4 migration notes.
