    How to use

    Paste query parameters, choose duplicate-key policy and convert.

    Worked example

    user[name]=Ana&tags[0]=red yields {"user":{"name":"Ana"},"tags":["red"]}.

    Supported input

    URL-encoded strings; key brackets with bounded numeric array indexes.

    Assumptions & limitations

    Bracket notation is a convention, not a universal URL standard; ambiguous shapes are rejected.
