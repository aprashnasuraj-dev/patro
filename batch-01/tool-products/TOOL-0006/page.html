Sensitive debug log handling

Make HAR diagnostics safer to share

Privacy-first reconstruction keeps timing and status metrics while discarding URLs, cookies, headers, request bodies and unknown extension fields.

Designed for

Remove unknown fields · preserve latency diagnostics · privacy warning

The local browser workspace will load when this route is activated. You can read the instructions below without JavaScript.

How to use this tool

Import your HAR file, confirm the request counts, run the privacy scrub and inspect the downloaded file before sharing.

Worked example

Try this representative input to inspect the output and its warnings:

{"log":{"version":"1.2","entries":[{"startedDateTime":"2026-10-26T00:00:00Z","time":30,"request":{"method":"GET","url":"https://example.com/private?token=secret","headers":[{"name":"Authorization","value":"Bearer secret"}]},"response":{"status":200,"content":{"text":"sensitive response","size":100},"headers":[{"name":"Set-Cookie","value":"session=secret"}]},"timings":{"wait":22,"receive":8}}]}}

Supported formats and constraints

HAR 1.2 JSON, up to 500 entries

Even stripped network timing/status data can reveal traffic patterns. Do not treat automated redaction as a legal data de-identification guarantee.

Privacy and safety

Source is prepared for local browser execution. There is no automatic upload or third-party conversion API; verify actual behavior during the post-import testing stage. Review any exported content before sharing or executing it.
