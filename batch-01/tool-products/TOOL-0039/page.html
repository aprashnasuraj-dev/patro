How to use

Copy your server’s PEM certificate chain, leaf first and intermediates after it, into the input. Use Verify certificate order. A synthetic three-certificate example is preloaded: leaf, intermediate, root. The tool verifies both signatures using the issuer public keys. If reversed, it reports incorrect order. Optional UTC inspection date enables a historical validity check. Never paste private keys.

Supported inputs

RFC 7468 CERTIFICATE PEM, X.509 DER, RSA PKCS#1 v1.5 SHA-1/256/384/512, RSA-PSS when MGF1 uses the same hash, ECDSA with P-256/P-384/P-521, and Ed25519 where browser support exists. Maximum 20 certificates, 128 KB DER each, 512,000 characters total. Unknown algorithms and unsupported critical extensions produce an explicit unsupported result. This is a chain order inspector—not trust-path validation.

Privacy and performance

The tool executes in your browser, needs no account, and sends no input to a server. The script is loaded only when this page is opened. The PEM field is limited to 512,000 characters. WebCrypto runs only in HTTPS or localhost secure contexts.
