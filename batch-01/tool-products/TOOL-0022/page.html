Pipeline migration map: GitHub Actions to GitLab CI Converter

Produce a GitLab CI draft for a strict subset of GitHub Actions jobs with explicit unsupported-feature findings.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste a minimal GitHub Actions YAML with run-only steps. Inspect migration blockers before using the output.

Worked example

Example input:

name: Build
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - run: echo ok

Choose Draft GitLab pipeline to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Not semantically equivalent for marketplace actions, permissions, secrets, matrices, expression contexts, caches or triggers. Requires manual credentials and runtime review.
