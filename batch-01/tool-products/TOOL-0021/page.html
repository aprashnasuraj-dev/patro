Resource quantity explorer: Kubernetes CPU and Memory Units Converter

Convert Kubernetes CPU and memory quantity syntax into explicit cores, millicores, bytes and IEC/SI units.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Enter CPU and memory quantities separately. Review rounding and scheduler unit conventions.

Worked example

Example input:

cpu=250m
memory=512Mi

Choose Convert resource quantities to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Kubernetes resource quantities are decimal fixed-point or binary SI, not ordinary human-language units. Values can be extremely large; precision is preserved with integer/fraction arithmetic where feasible.
