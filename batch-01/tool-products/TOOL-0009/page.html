Deployment secrets

Convert a local .env file into Kubernetes Secret YAML

Generate clear base64-encoded data and visibly warn that base64 does not encrypt anything.

Designed for

No uploads · base64 is not encryption · namespace-aware

The local browser workspace will load when this route is activated. You can read the instructions below without JavaScript.

How to use this tool

Paste the .env source, supply a Kubernetes Secret name and namespace, export YAML and store it through a secure secret workflow.

Worked example

Try this representative input to inspect the output and its warnings:

# Development-only demonstration values
API_USER=example
API_PASSWORD="placeholder-not-real"
LOG_LEVEL=info

Supported formats and constraints

Literal .env; Kubernetes v1 Secret Opaque YAML

This converter does not evaluate shell variables. Kubernetes Secrets are not encrypted simply because values are base64 encoded. Avoid committing manifests containing real credentials.

Privacy and safety

Source is prepared for local browser execution. There is no automatic upload or third-party conversion API; verify actual behavior during the post-import testing stage. Review any exported content before sharing or executing it.
