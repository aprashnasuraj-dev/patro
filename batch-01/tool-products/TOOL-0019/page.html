Dependency version atlas: package-lock.json Duplicate Dependency Finder

Report package versions appearing at multiple package-lock v2/v3 locations and expose path-level evidence.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste a lockfile v2/v3; inspect package locations and version clusters before changing dependencies.

Worked example

Example input:

{"lockfileVersion":3,"packages":{"":{"name":"sample"},"node_modules/a":{"version":"1.0.0"},"node_modules/b/node_modules/a":{"version":"2.0.0"}}}

Choose Find duplicated packages to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Multiple versions of the same package are not automatically a vulnerability or redundant install; deduplication can break semver constraints.
