How to use

Paste a Dockerfile, review ordered suggestions for cache invalidation and shell safety.

Worked example

Example input:

FROM node:22-alpine
WORKDIR /app
COPY . .
RUN npm install
CMD ["node", "app.js"]

Choose Inspect Dockerfile to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.
