Release override planner: Helm values.yaml to --set Flags

Flatten Helm values with safe --set-json flags, keeping booleans, arrays and strings distinct.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste Helm values and export shell-quoted --set-json arguments. Avoid passing credentials via shell arguments.

Worked example

Example input:

replicaCount: 2
image:
  repository: nginx
  tag: "1.27"
feature:
  enabled: true

Choose Generate Helm flags to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Uses a YAML parser at integration time; --set-json requires compatible Helm. Shell fragments contain safely quoted literal values; secrets passed in CLI arguments can appear in process lists.
