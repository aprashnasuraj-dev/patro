Conflict plan builder: JSON to PostgreSQL Upsert Generator

Generate reviewable parameter placeholders plus values manifest for PostgreSQL INSERT ON CONFLICT.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Supply rows with consistent column keys and choose an existing unique conflict column. Bind the accompanying JSON parameters in your database driver.

Worked example

Example input:

[{"id":1,"name":"Ada"},{"id":2,"name":"Lin"}]

Choose Generate upsert SQL to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Requires a real matching unique or exclusion constraint for conflict target. Generated placeholders are not interpolated SQL literals; bind parameter values in a trusted client.
