Structure comparison: Semantic JSON Diff (Ignore Key and Array Order)

Compare JSON documents by deep semantics: unordered object keys and optionally unordered arrays with duplicate counts preserved.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste two JSON documents separated by ---JSON-DIFF--- and inspect paths where values differ.

Worked example

Example input:

{"a":1,"items":[3,1,3]}
---JSON-DIFF---
{"items":[1,3,3],"a":1}

Choose Compare JSON to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Unordered arrays implement multiset semantics (duplicates matter); array sorting may erase meaningful sequence semantics. Large nested values are bounded to prevent resource exhaustion.
