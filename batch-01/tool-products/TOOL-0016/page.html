Traffic log analyzer: Nginx / Apache Access Log to CSV

Parse Common and Combined access log records into structured CSV with malformed line reporting.

Interactive workspace

On the published route, the tool module loads on demand. The source is prepared separately; this noindex page remains meaningful before hydration.

How to use

Paste access logs in common or combined format. Review rejected lines before exporting CSV.

Worked example

Example input:

127.0.0.1 - frank [10/Oct/2000:13:55:36 -0700] "GET /apache_pb.gif HTTP/1.0" 200 2326 "http://example.test/start" "TestAgent/1.0"

Choose Extract CSV to review the output. Representative expected-result scenarios are recorded in examples/fixtures.json.

Supported formats and limitations

Supports default CLF/Combined log formats, not custom log_format or JSON access logs. CSV values are quoted and spreadsheet-formula cells neutralized.

References and specifications

  • https://httpd.apache.org/docs/current/logs.html
  • https://nginx.org/en/docs/http/ngx_http_log_module.html
