Protocol schema design

Build an editable proto3 message draft from JSON

Generate nested messages and sample-based scalar fields, with warnings about long-term field tag stability.

Designed for

Wire-format ID awareness · proto3 syntax · schema evolution caution

The local browser workspace will load when this route is activated. You can read the instructions below without JavaScript.

How to use this tool

Paste representative JSON, choose a root message and protobuf package, then inspect field types and stable numeric tags before adoption.

Worked example

Try this representative input to inspect the output and its warnings:

{
  "customer_id": 12,
  "active": true,
  "name": "Mira",
  "addresses": [{"city": "Kathmandu", "zip": 44600}],
  "labels": ["regular", "email"]
}

Supported formats and constraints

JSON input; Protocol Buffers proto3 message and field grammar

Sample inference cannot establish absent fields, int64 precision, enums, map intent or safe future field numbers; do not reorder tags after deployment.

Privacy and safety

Source is prepared for local browser execution. There is no automatic upload or third-party conversion API; verify actual behavior during the post-import testing stage. Review any exported content before sharing or executing it.
