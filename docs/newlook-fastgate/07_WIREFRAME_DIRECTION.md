# 07 — Approved-to-implement design direction (specification, not screenshot)
Desktop: slim AppChrome header [brand | Calendar · Panchang · Festivals · Tools · About | search · theme · language · sign-in]. Hero: greeting above prominent BS date, AD/support, sun-path, source-backed day line, Full Panchang CTA. Main: calendar with month/week controls, legend and day panel. Sidebar: upcoming verified festivals, moon/sky, optional contextual utility (maximum 3–4). Below: five category entry tiles and structured footer. My space holds private note; no news on home.
Mobile: slim header; hero first; calendar swipe and Today; upcoming festivals; category entry; bottom tabs Calendar/Panchang/Tools/My space with safe area. No duplicated legacy MobilePrimaryNav overlay. A menu exposes all specialized routes and community/media/language helpers.
Visual: 8px grid; warm-paper semantic tokens; original dark tokens; Devanagari + Latin font pair and five type roles; subtle line iconography; no stock images or borrowed Mithila patterns; reduced-motion-safe calendar slide.
Festival/date: reusable header/art with source-backed facts, separated holiday/observance labels, countdown only for valid exact dates; empty states when unavailable.
Interaction frames to review at 360/390/768/1280/1440: initial, expanded menu, calendar selected/hover, empty/error/offline, festival, Tools hub and dark. Layout spec is actionable; pixel-perfect screenshot sign-off awaits an actual browser preview in #03/#50.
**Decision log:** retain all existing routes, source logic, auth/search, personalization storage keys; refine navigation presentation only. Alternative rejected: full static rebuild/new router (high regression risk to edge handlers and SEO, no meaningful benefit for this redesign).
