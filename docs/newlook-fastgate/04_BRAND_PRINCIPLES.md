# 04 — Brand and creative specification
**Sentence:** Aafnai Patro is a warm, culturally grounded, calm and precise daily Nepali almanac, presented with modern bilingual clarity.
**Principles:** Daily ritual before dashboard; calendar first; accuracy visible rather than asserted; warm paper and restrained cultural references; one visual grammar across light/dark; informative before decorative; diaspora-friendly translation without changing original data.
**Use:** large BS date, clear source-backed Panchang, quiet off-white surfaces, crimson for actual holiday, separate active selection token, deep blue for navigation, single outline icon style, five text roles, consistent 8px spacing, reduced-motion-safe interaction.
**Avoid:** mixed dark/cream cards, decorative rainbow symbols, unsourced auspiciousness, violent headlines on home, festival-as-public-holiday equivalence, keyword walls, repeated install prompts, counterfeit cultural motifs and unlicensed local photography.
**Acceptance rubric:** Does it preserve factual output and existing URL? Is each semantic color unambiguous? Can a user recognize Today vs selected vs holiday without color alone? Is full Nepali readable? Is English equivalent? Does mobile lead with date/calendar? Is data provenance and absence honest? Does keyboard/reduced motion work?
**Creative constraints:** Flag-color proposals #DC143C and #003893 are starting points rather than asserted official digital brand guidelines; calibrate accessible tokens in #08. Seasonal accents use existing festival data only. No artist asset without license and credit.
