Fixed-Width Text to CSV Converter

Split fixed-position records into columns and export RFC 4180-style CSV without sending the data anywhere.

Use widths like 10,5,12 or 1-based ranges like 1-10,11-15,16-27.

What this tool does

Split fixed-position records into columns and export RFC 4180-style CSV without sending the data anywhere.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

With widths 10,5,12, “ALICE     00042TOKYO       ” becomes three cells: ALICE, 00042, TOKYO.

Supported formats and units

CSV text; comma delimiter; CRLF output; quoted fields when needed.

Assumptions

Columns are character offsets, not display-cell widths; tabs are rejected because their visual width is ambiguous.

Limitations

Fixed-width files that depend on byte offsets in legacy encodings should be decoded correctly before pasting; this browser tool slices Unicode strings by code points.

References

  • RFC 4180

FAQ

Why are tabs rejected?

A tab does not have one intrinsic width; it depends on the viewer’s tab stop, so treating it as fixed width would produce misleading columns.
