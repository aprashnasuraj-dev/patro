Bulk Find and Replace with Rule Table

Apply ordered literal or regex replacement rules with a cancellable worker and a bounded runtime.

What this tool does

Apply ordered literal or regex replacement rules with a cancellable worker and a bounded runtime.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

A literal rule pending→ready changes both rows; a second regex rule can then rewrite order numbers.

Supported formats and units

Plain text plus up to 100 sequential rules; regex rules use the browser JavaScript RegExp engine inside a dedicated worker.

Assumptions

Rules are applied in order. Regex pattern length, text size and runtime are bounded.

Limitations

A single JavaScript regular expression can still exhibit engine-dependent behavior; the worker is terminated on timeout, so no partial output is returned after a timeout.

References

  • No external standard is required for the core transformation; implementation behavior is documented above.

FAQ

Why a worker?

A pathological regular expression can monopolize the main thread. Running it in a worker lets the UI cancel or terminate the job.
