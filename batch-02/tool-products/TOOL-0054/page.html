What this tool does

Probe localStorage writes only in the current origin, then remove every temporary key.

How to use it

Set a conservative maximum and choose Run probe. The probe never deletes your existing storage.

Worked example

A 512 KiB probe reports at least 512 KiB writable if all temporary writes succeed.

Supported inputs & assumptions

Browser localStorage on the current origin; byte counts are UTF-16 estimates.

Known limitations

Not a true maximum quota measurement: origin storage, security settings and other tabs vary.
