Font Subsetter (TTF/OTF/WOFF2)

Keep only requested Unicode characters in a font, with licensing/layout guards and local browser processing.

What this tool does

Keep only requested Unicode characters in a font, with licensing/layout guards and local browser processing.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

A simple TrueType Latin font can be subset to the characters in a logo or landing page and exported as WOFF2.

Supported formats and units

TTF, OTF or WOFF2 input; output TTF/WOFF2 only after safe eligibility checks.

Assumptions

The implementation refuses fsType “no subsetting” fonts and refuses fonts with complex layout tables (GSUB/GPOS/GDEF) in this first production path because the selected browser library can drop layout behavior during subset rewriting.

Limitations

fsType is not a complete license. Users still need rights to modify/subset a font. CFF/CFF2 and complex-script fonts can be rejected even when the file is structurally valid.

FAQ

Why can a font be rejected?

A smaller file is not useful if it silently loses ligatures, shaping or violates embedded no-subsetting metadata. The tool fails closed for those cases.
