WordCountShareFrequency

What this tool does

Count words locally with Unicode-aware segmentation, optional normalization and a visible stopword policy.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

“data” appears twice after case-folding, while common stopwords can be excluded from the ranked list.

Supported formats and units

Unicode text; Intl.Segmenter is preferred where available; fallback uses Unicode letter/number regex.

Assumptions

Stopwords are a small transparent built-in English set, not a language model.

Limitations

Tokenization of CJK, Thai, hashtags, apostrophes and domain-specific compounds can vary by browser segmentation support.

References

  • No external standard is required for the core transformation; implementation behavior is documented above.

FAQ

Does the text leave my browser?

No. Counting, normalization and CSV export are local.
