What this tool does

Expand shorthand addresses, compress the longest zero sequence and compare notation.

How to use it

Paste an IPv6 address, including optional IPv4-mapped suffix, and calculate.

Worked example

2001:0DB8:0:0:0:0:0:1 → 2001:db8::1.

Supported inputs & assumptions

RFC 4291 IPv6 text format and RFC 5952 canonical lowercase compression.

Known limitations

Zone identifiers, CIDR prefixes and hostnames are intentionally unsupported.
