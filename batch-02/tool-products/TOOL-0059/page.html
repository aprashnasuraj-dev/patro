What this tool does

Generate the required contact and expiry fields plus optional canonical and policy links.

How to use it

Enter a reporting contact and expiry UTC timestamp; copy the published file content.

Worked example

Contact: mailto:security@example.com and Expires: 2027-01-01T00:00:00Z.

Supported inputs & assumptions

UTF-8 text for /.well-known/security.txt over HTTPS.

Known limitations

No file hosting, signing, ownership proof or mailbox monitoring is performed.
