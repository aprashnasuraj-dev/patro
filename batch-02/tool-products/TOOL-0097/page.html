What this tool does

Apply transparent, rule-based title capitalization profiles and explain every changed token.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

Chicago 18 keeps short prepositions lowercase (unless first/last) while capitalizing prepositions longer than four letters under its updated rule.

Supported formats and units

English titles; punctuation/hyphen boundaries are handled conservatively.

Assumptions

Profiles use explicit stopword/length rules, not full part-of-speech parsing.

Limitations

Real editorial rules depend on grammar, proper nouns, branded capitalization and context. AP guidance is proprietary and nuanced; the AP profile is an approximation and should not be represented as official AP Stylebook output.

FAQ

Why does the tool show a decision table?

Title-case rules are contextual. The table makes the automated choice reviewable instead of hiding it.
