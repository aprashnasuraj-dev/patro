What this tool does

Inspect user-perceived characters as grapheme clusters, then drill down to Unicode code points, UTF-16 units and UTF-8 bytes.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

The astronaut sequence is one grapheme cluster but multiple code points joined with ZWJ.

Supported formats and units

Unicode text; default grapheme segmentation via Intl.Segmenter where available.

Assumptions

Grapheme boundaries are browser-implementation data aligned with Unicode segmentation; emoji classification uses Unicode property escapes when available.

Limitations

The tool does not ship the full Unicode character-name database, so it shows scalar values and encodings rather than potentially stale names. Platform emoji rendering can differ.

FAQ

Why is one visible emoji several code points?

Unicode emoji can be sequences containing base characters, modifiers, variation selectors, regional indicators and zero-width joiners.
