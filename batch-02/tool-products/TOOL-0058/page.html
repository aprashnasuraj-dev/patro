What this tool does

Build RFC 7489 policies with constrained tags and an implementation checklist.

How to use it

Select monitoring, quarantine or reject; optionally add report mailboxes and alignment.

Worked example

v=DMARC1; p=none; rua=mailto:dmarc@example.com monitors aggregate reports.

Supported inputs & assumptions

DMARC1 with p, sp, pct, adkim, aspf, rua, ruf.

Known limitations

The generator cannot verify DNS publication, SPF/DKIM alignment or external reporting authorization.
