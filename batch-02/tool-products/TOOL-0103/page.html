WOFF2 to TTF Converter

Decode WOFF2 locally and download TTF only when the decompressed SFNT uses TrueType outlines.

What this tool does

Decode WOFF2 locally and download TTF only when the decompressed SFNT uses TrueType outlines.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

A WOFF2 generated from a TrueType font decodes back to an sfnt TTF payload and can be downloaded.

Supported formats and units

WOFF2 input up to 30 MB.

Assumptions

The decompressed SFNT signature must be TrueType-compatible before the output is named .ttf.

Limitations

WOFF2 can wrap CFF/OpenType data. If decoding yields an OTTO/CFF font, this tool refuses to mislabel it as TTF rather than performing a potentially lossy outline conversion.

FAQ

Why might a valid WOFF2 be refused?

WOFF2 is a container, not an outline type. A valid WOFF2 can contain CFF/OpenType outlines, which are not truthfully a TTF output.
