What this tool does

Estimate English readability with six established metrics and show the counts that drive each score.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

The tool reports Flesch Reading Ease, Flesch-Kincaid grade, Gunning Fog, SMOG, Coleman-Liau and ARI from the same visible word/sentence counts.

Supported formats and units

English prose; Unicode letters are counted; sentence boundaries use punctuation heuristics.

Assumptions

English syllables are estimated locally with a deterministic heuristic.

Limitations

Scores are estimates. Proper nouns, abbreviations, numbers, domain jargon and multilingual text can materially alter formula validity; SMOG is most stable on longer samples.

FAQ

Why can this differ from Microsoft Word?

Different tokenization and syllable dictionaries change counts. The formulas can match while preprocessing differs.
