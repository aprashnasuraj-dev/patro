Excel Paste to Markdown Table

Paste spreadsheet cells as tab-separated clipboard data and turn them into a readable Markdown pipe table.

What this tool does

Paste spreadsheet cells as tab-separated clipboard data and turn them into a readable Markdown pipe table.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

A 3×3 spreadsheet selection becomes a Markdown header row, separator row, and two data rows.

Supported formats and units

Tab/newline clipboard text; quoted tabular fields are accepted; output is a GFM-style pipe table.

Assumptions

Excel/Sheets clipboard data is treated as TSV-like data.

Limitations

Merged cells, formulas, styling, and hidden rows are not represented in clipboard text and therefore cannot be reconstructed.

References

  • GitHub Flavored Markdown Spec
  • RFC 4180

FAQ

What happens to a | character in a cell?

It is escaped so it does not create an unintended Markdown column.
