Split a large sitemap into protocol-compliant parts and an optional index.

What it solves

Split by URL count and uncompressed XML size while keeping each generated file on-device.

Step-by-step

Review the sample inputs, replace with your own, activate “Split sitemap”, inspect warnings and result tables, then copy or download the output.

Worked example

https://example.com/a and /b form sitemap-001.xml; published base URL enables an index.

Supported inputs & assumptions

A sitemap URL list or one standard urlset XML document; up to 80,000 URLs and 8 MB of input.

Important limitations

URL-element extensions are preserved from XML input; document-level comments and unknown root metadata are not.
