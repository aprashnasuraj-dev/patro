FieldValue

What this tool does

Inspect OpenType names, metrics, table inventory and embedded license/embedding metadata without executing the font.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

The report can show family, subfamily, version, vendor/designer, glyph count, units/em, fsType interpretation and embedded name IDs 13/14.

Supported formats and units

TTF/OTF/WOFF2; name table, head/maxp/OS/2 and table-directory metadata.

Assumptions

Name strings prefer Windows English, then Unicode, then other available records.

Limitations

Embedded license text and OS/2 fsType are metadata, not legal advice and not proof of the actual EULA. A missing license field does not imply unrestricted use.

FAQ

Can I rely on fsType as the whole license?

No. fsType describes embedding restrictions; actual license terms may impose additional conditions.
