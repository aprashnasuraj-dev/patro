Variable Font Axes Inspector and CSS Generator

Read the OpenType fvar table, expose axis ranges and generate CSS without uploading the font.

What this tool does

Read the OpenType fvar table, expose axis ranges and generate CSS without uploading the font.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

A font with wght 300–900 and wdth 75–125 yields range controls and matching @font-face / font-variation-settings snippets.

Supported formats and units

Variable OpenType fonts with an fvar table.

Assumptions

Axis min/default/max values are read directly from fvar; WOFF2 is decoded before inspection.

Limitations

CSS high-level properties are generated for registered axes where safe, while custom axes use font-variation-settings. Browser behavior outside declared ranges is not assumed.

FAQ

What if the font has no fvar table?

It is not treated as a functional variable font by this inspector and an explicit message is shown.
