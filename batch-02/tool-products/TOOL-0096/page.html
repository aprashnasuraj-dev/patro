String Escape and Unescape for JSON, Java, Python, SQL, Regex

Escape or decode string-literal content without eval, code execution, or network requests.

What this tool does

Escape or decode string-literal content without eval, code execution, or network requests.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

JSON mode converts a newline into \n and a quote into \"; unescape reverses valid JSON escapes.

Supported formats and units

JSON, Java, Python, SQL single-quoted literal content, and JavaScript-style regex pattern text.

Assumptions

No eval is used. Unescape parsers accept only documented sequences for the selected mode.

Limitations

Python named Unicode escapes (\N{...}), Java text blocks, PostgreSQL dollar quoting, SQL dialect-specific backslash modes and regex replacement-string syntax are intentionally out of scope.

References

  • Java SE 26 JLS

FAQ

Can I paste executable code?

Yes as text, but it is never executed. The parser only transforms string escape sequences.
