What this tool does

Create escaped XML sitemap entries with optional ISO publication dates.

How to use it

Paste absolute URLs, optionally URL,lastmod, then download the UTF-8 XML.

Worked example

https://example.com/about,2026-10-01 becomes one urlset entry.

Supported inputs & assumptions

Sitemaps protocol, Google 50,000 URL and 50MB uncompressed limits.

Known limitations

Do not confuse sitemap creation with publication, crawl, indexing or canonical verification.
