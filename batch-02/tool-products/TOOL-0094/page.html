What this tool does

Remove editor-specific cruft and unsafe HTML while keeping useful document structure.

How to use it

Enter or choose the source data, review the task-specific options, run the primary action, inspect warnings and results, then copy or download only if the output is suitable.

Worked example

Supported formats and units

HTML fragment from clipboard or text; output is a conservative semantic subset.

Assumptions

Sanitization uses DOMParser, an explicit allowlist and URL-scheme checks; no untrusted HTML is executed.

Limitations

The cleaner intentionally removes style fidelity, embedded objects, scripts, forms, tracking attributes and unsupported editor metadata.

FAQ

Does this preserve exact Word formatting?

No. The goal is clean web-ready structure, not round-trip fidelity.
