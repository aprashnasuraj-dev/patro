Local-Only Net Worth Tracker

Track assets and liabilities entirely in the browser, calculate net worth and category totals, and export or re-import a local JSON snapshot. Normal use stays in this browser and sends no tool input to a server.

Local balance sheet

No account · no server · optional browser storage only

One line per item: type, category, name, value. Type is asset or liability.

What this tool does

Track assets and liabilities entirely in the browser, calculate net worth and category totals, and export or re-import a local JSON snapshot.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

The sample totals cash and retirement assets against a student-loan liability; names are displayed as text, not HTML.

Supported formats / units

Line input uses comma-delimited type,category,name,value; export/import uses local JSON snapshot format version 1.

Assumptions

Entries are nonnegative values classified as assets or liabilities; optional persistence uses localStorage only.

Limitations

Browser storage can be cleared; no encryption is added by this tool; do not store secrets.

FAQ

Where is my data stored?

Calculations are local; Save locally uses this browser's localStorage and export creates a local JSON file.
