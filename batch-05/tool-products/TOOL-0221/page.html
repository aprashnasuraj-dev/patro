What this tool does

Project a fixed-rate loan payoff with recurring extra payments, compare interest against the no-extra path, and export the amortization schedule.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

With the sample $25,000 balance, 7.5% APR, $550 payment and $100 extra, the tool builds a month-by-month payoff schedule and compares it with the $550-only path.

Supported formats / units

Currency values are unit-agnostic unless a specific jurisdiction is stated; percentages are entered as percent values (for example 7.5 for 7.5%).

Assumptions

Fixed APR, monthly interest accrual, payment at month end, no fees or prepayment penalties.

Limitations

Actual lender posting, daily interest, fees, payment holidays and penalties can change payoff results.

FAQ

Does extra payment always save interest?

For a positive-rate amortizing loan, earlier principal reduction usually lowers modeled interest. Prepayment penalties or servicer rules are outside this tool.
