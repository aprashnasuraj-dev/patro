RSU Vesting and Withholding Estimator

Estimate the gross value of an RSU vest, user-entered withholding, sell-to-cover shares and remaining shares without pretending withholding equals final tax liability. Normal use stays in this browser and sends no tool input to a server.

Vesting event

Enter payroll rates that apply to you. The 22% sample mirrors a U.S. supplemental-wage example, not a universal RSU tax rate.

What this tool does

Estimate the gross value of an RSU vest, user-entered withholding, sell-to-cover shares and remaining shares without pretending withholding equals final tax liability.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

250 shares at $48 create a $12,000 gross vest value before applying the entered withholding percentages.

Supported formats / units

Currency values are unit-agnostic unless a specific jurisdiction is stated; percentages are entered as percent values (for example 7.5 for 7.5%).

Assumptions

Vest value equals shares × entered price; withholding rates are user inputs; sell-to-cover uses the same entered price.

Limitations

Not tax advice; payroll and tax treatment varies by jurisdiction, award design and year.

FAQ

Is withholding the same as tax owed?

No. This tool only applies the withholding rates you enter to the vest value.
