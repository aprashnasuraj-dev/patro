Big Number Prime Factorization and GCD/LCM

Factor bounded large integers in a worker using BigInt Miller–Rabin and Pollard rho, and compute exact GCD/LCM. Inputs and calculations stay in the browser during normal use.

What this tool calculates

Factor bounded large integers in a worker using BigInt Miller–Rabin and Pollard rho, and compute exact GCD/LCM.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Input is a base-10 integer within the documented browser-safe bit bound.

Limitations

Factorization is deliberately capped at 128 bits and a fixed iteration budget. Values above 64 bits use probable-prime testing; this is not a proof-oriented computer algebra system.

FAQ

Is primality mathematically proven?

Through 64 bits the selected Miller–Rabin bases are deterministic; above that bound the tool labels results as probable-prime checks.
