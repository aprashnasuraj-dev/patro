Random Sampler with Seed (Reproducible)

Draw a reproducible seeded sample with or without replacement using a documented non-cryptographic PRNG. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Draw a reproducible seeded sample with or without replacement using a documented non-cryptographic PRNG.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Input order is part of reproducibility; duplicate lines are distinct sampling units.

Limitations

The PRNG is reproducible but not cryptographically secure. The same seed and same ordered input are required for identical results.

FAQ

Can this be used for passwords or tokens?

No. The generator is deliberately reproducible and is not cryptographically secure.
