What this tool does

Compare two fixed-rate installment loans on monthly payment, interest, fees and total cash cost using consistent assumptions.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

The sample compares two $25,000 loans with different rates, terms and upfront fees on total cash paid.

Supported formats / units

Currency values are unit-agnostic unless a specific jurisdiction is stated; percentages are entered as percent values (for example 7.5 for 7.5%).

Assumptions

Fixed-rate equal monthly payment loans; upfront fees are added to total cash cost, not financed unless reflected in principal.

Limitations

Does not compute legal APR, variable rates, prepayment effects or tax consequences.

FAQ

What if loan amounts differ?

The tool warns because total cash cost is not a like-for-like price comparison when principals differ.

Authoritative references

  • No external reference required for the deterministic arithmetic implemented here; assumptions are stated explicitly.
