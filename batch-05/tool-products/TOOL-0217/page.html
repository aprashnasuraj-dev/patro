Matrix Calculator with Step-by-Step Inverse and Determinant

Calculate determinant, inverse, or RREF with partial pivoting and a readable row-operation trace. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Calculate determinant, inverse, or RREF with partial pivoting and a readable row-operation trace.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Matrix entries are finite real numbers; displayed row operations are rounded only for presentation.

Limitations

Floating-point elimination can be ill-conditioned. The tool uses partial pivoting and an epsilon threshold, but it is not arbitrary-precision or symbolic algebra.

FAQ

Why partial pivoting?

Choosing a larger available pivot reduces numerical instability compared with naïve elimination.

Method references

  • NIST DLMF §3.2 — Linear Algebra / Gaussian elimination with partial pivoting
