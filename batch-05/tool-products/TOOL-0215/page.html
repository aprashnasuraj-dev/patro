What this tool calculates

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Prevalence is the pre-test probability and sensitivity/specificity are conditional test characteristics.

Limitations

Predictive values are prevalence-dependent. Sensitivity/specificity supplied from one population may not transport to another population.

FAQ

Why can PPV be low for an accurate test?

When the condition is rare, false positives among many unaffected people can outnumber true positives.
