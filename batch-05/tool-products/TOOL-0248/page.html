What this tool does

Add or reverse VAT/GST from a gross or net amount, or process a bounded CSV batch with explicit rate and mode for each row.

How to use it

Review the sample state, replace it with your own bounded inputs, run the tool, then inspect the formula trail, warnings and assumptions before copying or exporting the result.

Worked example

For a tax-inclusive amount of 120 at 20%, the reverse calculation returns net 100 and tax 20 under exact decimal arithmetic before display rounding.

Supported formats / units

Numeric fields accept finite decimal values inside the displayed/tool-specific bounds. Dates use ISO-style browser date inputs. CSV/document tools state their accepted column format beside the input.

Assumptions

The user supplies the applicable tax rate and whether each amount is tax-inclusive or tax-exclusive. The tool is not a jurisdictional tax-rate database.

Limitations

Tax rules differ by jurisdiction, product and transaction. Rounding requirements can also differ, especially across invoice-level versus line-level tax.

FAQ

Does this tool send my inputs anywhere?

No during normal use. The production intent is browser-side computation with dependencies bundled/lazy-loaded by route where needed.

Is this a legal, tax, payroll or accounting determination?

No. Where rules can vary by jurisdiction or contract, the tool exposes user-entered policy assumptions and explicit warnings instead of silently selecting a rule.
