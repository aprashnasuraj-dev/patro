Binomial and Poisson Probability Calculator

Calculate binomial or Poisson point, cumulative, tail, and interval probabilities without factorial overflow. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Calculate binomial or Poisson point, cumulative, tail, and interval probabilities without factorial overflow.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Distribution parameters correspond to the mathematical binomial or Poisson model.

Limitations

The binomial assumes fixed n, independent Bernoulli trials, and constant p. The Poisson assumes a constant event rate over the exposure interval.

FAQ

How are large factorials avoided?

Point probabilities use log-gamma arithmetic and cumulative probabilities use regularized beta/gamma functions.
