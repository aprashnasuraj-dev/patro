Compound Interest Calculator with Inflation-Adjusted Returns

Project compound growth with monthly contributions and show both nominal future value and inflation-adjusted purchasing power. Normal use stays in this browser and sends no tool input to a server.

Growth projection

What this tool does

Project compound growth with monthly contributions and show both nominal future value and inflation-adjusted purchasing power.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

The sample projects $10,000 plus $500/month for 20 years at 7%, then discounts the result by 2.5% annual inflation.

Supported formats / units

Currency values are unit-agnostic unless a specific jurisdiction is stated; percentages are entered as percent values (for example 7.5 for 7.5%).

Assumptions

Monthly compounding and end-of-month contributions; constant return and inflation assumptions.

Limitations

Constant returns hide volatility and sequence risk; fees and taxes are excluded.

FAQ

Why show inflation-adjusted value?

It expresses the modeled future balance in today's purchasing-power terms under the entered inflation rate.
