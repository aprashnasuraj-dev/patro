Inflation Calculator with Custom Rate

Apply a user-entered constant inflation rate forward or backward across a chosen number of years and show the year-by-year purchasing-power path. Normal use stays in this browser and sends no tool input to a server.

Custom inflation path

What this tool does

Apply a user-entered constant inflation rate forward or backward across a chosen number of years and show the year-by-year purchasing-power path.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

$1,000 at 3% custom inflation for 10 years is multiplied by 1.03^10 in forward mode.

Supported formats / units

Currency values are unit-agnostic unless a specific jurisdiction is stated; percentages are entered as percent values (for example 7.5 for 7.5%).

Assumptions

Constant annual custom inflation rate with annual compounding.

Limitations

No external inflation index is used; a constant rate is an abstraction.

FAQ

Does this use CPI data?

No. It applies only the custom constant rate you enter.

Authoritative references

  • No external reference required for the deterministic arithmetic implemented here; assumptions are stated explicitly.
