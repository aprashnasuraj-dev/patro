Employer Retirement Match Calculator (Custom Formula)

Model a custom tiered employer retirement match against salary and employee contribution rate, including caps and optional vesting percentage. Normal use stays in this browser and sends no tool input to a server.

Employer match formula

Tier format: from %, to %, employer match % of employee contribution in that band.

What this tool does

Model a custom tiered employer retirement match against salary and employee contribution rate, including caps and optional vesting percentage.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

The sample matches 100% of the first 3% of salary contribution and 50% of the next 2%.

Supported formats / units

Tier lines use from-percent,to-percent,match-percent.

Assumptions

Tier bands are non-overlapping percentages of salary contribution; employer match may be capped then optionally reduced by vesting percentage.

Limitations

Plan documents can include eligibility, compensation definitions, caps, true-up rules and vesting conditions not represented here.

FAQ

What is a tier band?

Each line applies a match percentage only to the employee contribution rate between the tier's start and end percentages.
