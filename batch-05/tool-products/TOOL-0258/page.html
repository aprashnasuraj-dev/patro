Bulk Barcode Generator (EAN-13, UPC-A, Code 128) with Check Digit

Validate or append GS1 check digits for EAN-13 and UPC-A values, generate Code 128 when requested, and render a bounded batch of browser-side barcode SVGs. Normal use stays in this browser and does not transmit tool input to a server or third party.

What this tool does

Validate or append GS1 check digits for EAN-13 and UPC-A values, generate Code 128 when requested, and render a bounded batch of browser-side barcode SVGs.

How to use it

Review the sample state, replace it with your own bounded inputs, run the tool, then inspect the formula trail, warnings and assumptions before copying or exporting the result.

Worked example

EAN-13 data digits 400638133393 produce check digit 1; the rendered result is 4006381333931.

Supported formats / units

Numeric fields accept finite decimal values inside the displayed/tool-specific bounds. Dates use ISO-style browser date inputs. CSV/document tools state their accepted column format beside the input.

Assumptions

EAN-13 and UPC-A validation covers digit count and check digit; ownership/allocation of GS1 identifiers is not validated. Code 128 accepts printable ASCII in this implementation.

Limitations

Barcode dimensions and print quality matter in production. Screen rendering is not a substitute for verifier-grade symbol testing or GS1 allocation/packaging compliance.

FAQ

Does this tool send my inputs anywhere?

No during normal use. The production intent is browser-side computation with dependencies bundled/lazy-loaded by route where needed.

Is this a legal, tax, payroll or accounting determination?

No. Where rules can vary by jurisdiction or contract, the tool exposes user-entered policy assumptions and explicit warnings instead of silently selecting a rule.
