Monte Carlo Project Estimate Simulator (PERT)

Simulate sequential project duration from optimistic, most-likely, and pessimistic Beta-PERT task estimates with a reproducible seed. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Simulate sequential project duration from optimistic, most-likely, and pessimistic Beta-PERT task estimates with a reproducible seed.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Each row is a sequential task with optimistic ≤ most likely ≤ pessimistic and a non-zero range.

Limitations

Tasks are modeled as independent and sequentially additive. Dependencies, parallel branches, resource constraints, and critical-path logic are not modeled.

FAQ

Does this calculate a critical path?

No. It sums independent sequential task durations; network dependencies and resource constraints are outside this tool.
