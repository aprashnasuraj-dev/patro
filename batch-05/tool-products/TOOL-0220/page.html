Effect Size Calculator (Cohen's d, Hedges' g, Glass's delta)

Calculate Cohen's d, bias-corrected Hedges' g, and Glass's delta from two-group summary statistics with approximate confidence intervals. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Calculate Cohen's d, bias-corrected Hedges' g, and Glass's delta from two-group summary statistics with approximate confidence intervals.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Two independent groups summarized by sample size, arithmetic mean, and sample SD.

Limitations

Standardized mean differences depend on study design and denominator choice. Generic magnitude labels are intentionally omitted because interpretation is context-specific.

FAQ

Which effect size should I report?

That depends on design and variance assumptions. Hedges' g corrects small-sample bias; Glass's delta uses the selected control SD.
