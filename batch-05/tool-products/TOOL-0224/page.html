Coast FIRE and FIRE Number Calculator

Estimate a FIRE number in today's dollars and the invested balance needed today to coast toward that target using a real-return assumption. Normal use stays in this browser and sends no tool input to a server.

FIRE assumptions

What this tool does

Estimate a FIRE number in today's dollars and the invested balance needed today to coast toward that target using a real-return assumption.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

$48,000 annual spending with a 4% withdrawal assumption implies a $1.2 million FIRE number in today's dollars before coast discounting.

Supported formats / units

Currency values are unit-agnostic unless a specific jurisdiction is stated; percentages are entered as percent values (for example 7.5 for 7.5%).

Assumptions

Constant real return derived from nominal return and inflation; withdrawal rate is a planning input.

Limitations

Market returns and inflation are variable; FIRE sustainability requires broader portfolio and tax analysis.

FAQ

Is the withdrawal rate guaranteed?

No. It is a planning assumption, not a guarantee of portfolio sustainability.
