Debt list

One debt per line: name, balance, APR %, minimum payment.

Snowball and avalanche will use the same monthly budget.

What this tool does

Run the same debt list through snowball and avalanche repayment strategies using one fixed monthly budget, then compare payoff time, interest and payoff order.

How to use it

Review the prefilled example, replace it with your values, run the calculation, then read the assumptions and limitations before copying or exporting any result.

Worked example

The sample sends the same $695 monthly budget (minimums plus $300 extra) through both strategies so interest and payoff order are directly comparable.

Supported formats / units

Currency values are unit-agnostic unless a specific jurisdiction is stated; percentages are entered as percent values (for example 7.5 for 7.5%).

Assumptions

Monthly interest, fixed total budget, minimum payments applied before targeted extra funds, no new borrowing.

Limitations

Does not model credit-score effects, balance transfers, promotional rates or behavioral changes.

FAQ

Which strategy is mathematically cheaper?

With identical cash flow and no behavior changes, targeting the highest APR generally minimizes interest, but the tool shows both paths rather than prescribing one.
