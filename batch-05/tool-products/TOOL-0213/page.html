Z-Score to Percentile Calculator (Normal Distribution)

Convert a standard-normal Z-score to its left-tail percentile, right-tail probability, and symmetric two-sided tail probability. Inputs and calculations stay in the browser during normal use.

Inputs

Use the sample values or enter your own data, then run the tool.

What this tool calculates

Convert a standard-normal Z-score to its left-tail percentile, right-tail probability, and symmetric two-sided tail probability.

How to use it

Enter or paste the requested data, review the model choices shown beside the controls, run the calculation, then inspect warnings and method labels before copying or exporting the result.

Example

The form is preloaded with a bounded example so you can see the expected input shape before replacing it with your own data.

Assumptions

Z is expressed in standard-deviation units under N(0,1).

Limitations

A Z percentile assumes the standard normal model. It does not convert an arbitrary raw score unless the score was first standardized appropriately.

FAQ

Is percentile the same as one-sided p-value?

The left-tail percentile is Φ(z); the relevant p-value depends on the hypothesis direction and test design.
