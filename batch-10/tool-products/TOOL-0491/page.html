Interpretation & limits

    How to use this tool

    Start with the editable worked example, replace each assumption with information from your own records, then select the primary calculation action. Check every warning before using the result in a financial or operational decision.

    Worked example

    For 12,000 kWh delivered, a COP 3 heat pump uses 4,000 kWh electricity.

    Method and assumptions

    Delivered kWh demand is held constant; energy conversions are nominal.

    Supported inputs and limitations

    Installation cost and seasonal COP uncertainty are not included. Inputs are bounded, unsupported cases fail visibly, and locally entered data is not transmitted by this source package.

    Primary references

    US DOE Energy Saver: heating systems
