What it does

Estimate irrigation volume, runtime per equal-area zone, and estimated water draw using area, net inches, sprinkler-zone flow and irrigation efficiency.

How to use

  1. Choose the task-specific settings and provide Total planted area, Weekly target irrigation depth, Effective rainfall for the week.
  2. Press the calculation action and check outputs, assumptions and any warnings before relying on the figures.
  3. Copy the explanation or export the local JSON estimate when a record is needed.

Worked example

For 2,000 ft², 0.75 net inches, 80% efficiency, 8 gal/min over four equal zones, runtime is approximately 36.5 minutes per zone.

Supported inputs and measurement

numeric quantities. Each numeric field is bounded and finite. Units stated beside inputs remain the source of truth; conversion only occurs when explicitly indicated.

Assumptions and limitations

This is an equal-size zone estimate: actual run times should use catch-can precipitation-rate measurements, local evapotranspiration, soil infiltration and watering restrictions. Water balance cannot be fixed by runtime alone.

FAQ: is this an official determination?

No. This is a transparent local estimate, classification, or screening. The primary standards, governing local rules, product documents and measured facts control authoritative decisions.
