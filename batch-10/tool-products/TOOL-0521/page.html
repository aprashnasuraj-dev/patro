    What this tool does

    Count US physical-presence days from entry/exit logs and compare with standard 3-year or 5-year naturalization thresholds.

    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    A permanent resident five-year anniversary of January 15 gives a possible early-filing start 90 days before, only if other criteria met.

    Inputs and assumptions

    30 months/913 days in 5 years or 18 months/548 days in 3 years; USCIS counts departure and return days in US.

    Supported cases and exclusions

    Continuous residence, tax and morality conditions not certified. All values are bounded and malformed inputs are rejected rather than silently converted.
