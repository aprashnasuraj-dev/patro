    What this tool does

    Estimate untracked star-exposure duration from focal length, aperture, pixel pitch and declination using explicitly attributed NPF formulas.

    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    20 mm, f/2.8, 5.9-micron sensor at celestial equator gives an exposure estimate rather than an exposure guarantee.

    Inputs and assumptions

    Attributed full NPF: k(16.856N +0.0997f +13.713p)/(f cos δ); simplified estimate (35N+30p)/f.
