    What this tool does

    Size quilt backing, batting and binding strips with width-of-fabric assumptions, seam allowances and edge margins.

    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    A 70×90-inch quilt with 4-inch margin requires at least 78×98 inches backing and batting.

    Inputs and assumptions

    Backing panels = ceil((quilt width + overhang) / (usable fabric width net seams)); strip count uses perimeter and diagonal joins.

    Supported cases and exclusions

    No motif-match, shrinkage or bias-binding algorithms. All values are bounded and malformed inputs are rejected rather than silently converted.
