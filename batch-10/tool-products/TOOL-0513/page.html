    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    Federal worker after 6 years: C$72,000 qualifying wages × 6% = C$4,320 vacation pay.

    Inputs and assumptions

    Federal annual vacation 4%, 6%, 8% based on completed service; Ontario ordinarily 4% or 6%. Enter legal qualifying wages.

    Supported cases and exclusions

    This is not an automatically validated province-wide entitlement calculator. All values are bounded and malformed inputs are rejected rather than silently converted.
