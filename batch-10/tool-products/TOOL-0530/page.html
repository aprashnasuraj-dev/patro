    What this tool does

    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    A $100 sale with 2.7% plus $0.30 fees costs $3.00 before any surcharge; fee-on-fee changes full recovery.

    Inputs and assumptions

    Card proceeds = sticker price×(1+surcharge)×(1−processor %) − flat processing fee; cash proceeds = sticker×(1−cash discount).

    Supported cases and exclusions

    Legal compliance cannot be inferred solely from numeric economics or processor contracts. All values are bounded and malformed inputs are rejected rather than silently converted.
