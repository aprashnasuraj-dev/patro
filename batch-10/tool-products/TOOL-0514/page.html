    What this tool does

    Model unused concessional contribution capacity across five prior financial years, consuming oldest eligible unused cap first.

    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    A$30,000 current cap less A$18,000 already contributed leaves A$12,000 of normal current-year room.

    Inputs and assumptions

    Unused concessional cap amounts from five prior years are generally usable if total super balance was under $500,000 at previous 30 June.

    Supported cases and exclusions

    Prior-year amounts must be entered from official ATO records; no ATO account lookup. All values are bounded and malformed inputs are rejected rather than silently converted.
