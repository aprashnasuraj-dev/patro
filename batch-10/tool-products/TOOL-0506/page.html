Interpretation & limits

    How to use this tool

    Start with the editable worked example, replace each assumption with information from your own records, then select the primary calculation action. Check every warning before using the result in a financial or operational decision.

    Worked example

    £1,500 per month rent with £200k at 5.5% stress implies ~163.6% ICR.

    Method and assumptions

    Interest-only stress formula: monthly rental income / (loan balance × annual stress rate / 12).

    Supported inputs and limitations

    Not a lending eligibility determination. Inputs are bounded, unsupported cases fail visibly, and locally entered data is not transmitted by this source package.
