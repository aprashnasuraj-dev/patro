    What this tool does

    Compare a home battery’s net installation expense with displaced grid imports and foregone feed-in tariffs using annual cash flows.

    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    8 kWh/day × 365 × (0.9×A$0.34 − A$0.07) minus A$70 ≈ A$619/year before degradation.

    Inputs and assumptions

    Annual savings = solar shifted × (round-trip efficiency × import tariff − lost export tariff) minus annual cost, with degradation.

    Supported cases and exclusions

    Programs, dynamic tariffs and discharge limitations can substantially change the result. All values are bounded and malformed inputs are rejected rather than silently converted.
