    How to use this tool

    Start with the editable worked example, replace each assumption with information from your own records, then select the primary calculation action. Check every warning before using the result in a financial or operational decision.

    Worked example

    1024 Wh × 0.9 × 0.88 ÷ 250 W ≈ 3.24 hours.

    Method and assumptions

    Battery AC output models energy as capacity × depth × inverter efficiency.

    Supported inputs and limitations

    Generator rate must be measured or published at specified load. Inputs are bounded, unsupported cases fail visibly, and locally entered data is not transmitted by this source package.
