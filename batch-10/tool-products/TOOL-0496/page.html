    How to use this tool

    Start with the editable worked example, replace each assumption with information from your own records, then select the primary calculation action. Check every warning before using the result in a financial or operational decision.

    Worked example

    An owner who died in 2022 ordinarily has a 10-year distribution deadline of Dec 31, 2032.

    Method and assumptions

    Only traditional IRA, ordinary designated beneficiary, and confirmed factor supported.

    Supported inputs and limitations

    Factor cannot be computed automatically without beneficiary classification and age table. Inputs are bounded, unsupported cases fail visibly, and locally entered data is not transmitted by this source package.
