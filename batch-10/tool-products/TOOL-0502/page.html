Interpretation & limits

    How to use this tool

    Start with the editable worked example, replace each assumption with information from your own records, then select the primary calculation action. Check every warning before using the result in a financial or operational decision.

    Worked example

    $400,000 inherited FMV plus $12,000 qualified improvements gives $412,000 before selling expenses.

    Method and assumptions

    User supplies the estate-accepted valuation; no automatic estate appraisal.

    Supported inputs and limitations

    Qualified personal-residence and depreciated real-property treatment not computed. Inputs are bounded, unsupported cases fail visibly, and locally entered data is not transmitted by this source package.
