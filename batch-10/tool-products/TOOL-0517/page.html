    What this tool does

    Compare remaining cash flows for an assumable fixed-rate mortgage against a replacement purchase mortgage without hiding the equity gap.

    How to use it

    Use the prefilled worked example to understand the inputs. Replace each sample value with values from your own records and authoritative sources. Run the calculation and read all warnings before making a decision.

    Worked example

    An assumed 2.85% mortgage can have lower monthly debt service but require an upfront equity gap.

    Inputs and assumptions

    Level-payment amortization; fees and assumption equity gap displayed explicitly.

    Supported cases and exclusions

    Equal-house-price and equal-cash scenario require additional modeling beyond displayed lifetime totals. All values are bounded and malformed inputs are rejected rather than silently converted.
