Commercial Invoice & CN22/CN23 Generator

Prepare structured item totals, origin and HS fields for a shipping invoice and a non-official CN22/CN23 data worksheet, without forging carrier forms.

What this tool does

Local printable commercial invoice and customs worksheet. Prepare structured item totals, origin and HS fields for a shipping invoice and a non-official CN22/CN23 data worksheet, without forging carrier forms.

How to use

  1. Review the scope and enter exact, source-backed values.
  2. Run the calculation or generate the draft locally.
  3. Read assumptions and export for a second check.

Worked example

Sample inputs: Exporter name and address: Exporter Ltd; Address; Country, Consignee name and address: Importer Inc; Address; Country, ISO currency code: USD. The worked reference metric is Invoice goods value: USD 37.50. This is a deterministic example, not a runtime-tested result.

Supported formats and units

explicit choice, up to 100 characters, up to 4,000 UTF-16 code units. Numeric fields must be finite and within the displayed bounds. Lists and dates are checked for structure and plausible ranges.

Assumptions and known limitations

Official UPU postal form selection and destination-country customs requirements are not determined automatically.

FAQ: Is the output authoritative?

The result is not professional certification; the source inputs and governing rules control the decision.
