    How to use this tool

    Start with the editable worked example, replace each assumption with information from your own records, then select the primary calculation action. Check every warning before using the result in a financial or operational decision.

    Worked example

    Four 1000-lb animals at 2% DM intake need 80 lb total dry matter/day before losses.

    Method and assumptions

    Feed calculations use user-selected body weight and dry matter; no universal intake is implied.

    Supported inputs and limitations

    Not an animal-health or nutrition recommendation. Inputs are bounded, unsupported cases fail visibly, and locally entered data is not transmitted by this source package.
